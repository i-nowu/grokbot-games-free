# グンマー教の野望（ファミコン版）

GB版をファミコン（NES）に移植したタワーディフェンスです。栃木・茨城・埼玉・千葉・神奈川・東京の6面を守り抜くと、関東を開放したエンディングになります。

## 遊び方
`gunma.nes` をFCEUX などのファミコンエミュレーターで開いてください（マッパー30）。

## 確認済み
- 自動テストで6面すべてクリア、エンディングからタイトルに戻るまで確認
- タイトル曲が鳴ることを確認

## 未確認
- 戦闘中の曲と効果音
- 敵が多く並んだときのちらつき

これはフリーで配布されたゲームです。製品版はありません。もし買われた方がいたらそれは詐欺です。警察に相談してください。GrokBOTでチームを組んで作成しました。

## マッパー2版
- [gunma_mapper2.nes](gunma_mapper2.nes)：中身は同じで、マッパー2（UNROM）にしたROMです。6面とエンディングまで通しテスト済みです。
- バンク切り替えは、同じ値が入った表に書き込む方式なので、マッパー2の基板でも書き込みがぶつかりません。
