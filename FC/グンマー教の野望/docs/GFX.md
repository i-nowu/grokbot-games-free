# グラフィック（ファミコン版）
生成: `python3 tools/gfx/gen_gfx.py` → `src/gfx.c/h`、`python3 tools/gfx/gen_notice.py` → `src/gfx_notice.c/h`

- BG 216タイル（地形・ユニット・HUD・8x8ドットのフォント・全メッセージ・ED文）、スプライト 39タイル(8x8)
- メタタイル: `gfx_mt_tiles[mt*4+0..3]`（左上,右上,左下,右下）、パレットは `gfx_mt_pal[mt]`。ユニットは `MT_UNIT(種類,レベル)`
- 敵スプライト: `SPR_ENEMY(e,f)` から4枚(2x2)。パレット 0敵/1ボス/2弾・風/3カーソル
- タイトルロゴ: マップ用タイル(0〜)を上書きし、残りはフォントの後ろ。フォントはそのまま使えるので PUSH START 可。タイトルを抜けたら `gfx_bg_tiles` を読み直す
- 注意文画面: 専用55タイル + 32x30マップ。属性は全部パレット3
- **属性の注意**: `set_bkg_attributes_nes16x16` の元データは1バイトに4セル詰めた形式（属性テーブルと同じ8x8バイト）。
  `i=(y>>1)*8+(x>>1); sh=(((y&1)<<1)|(x&1))<<1;` で詰めてから送る。1セルずつ送ると壊れる
- 大量の書き込みは `DISPLAY_OFF` 中に行う（表示中はバッファがあふれて抜ける）
