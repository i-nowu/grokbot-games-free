# ファミコン版 グンマー教の野望 プログラムのメモ（GBプログラマー）

- 作り方: GBDK-2020 の `lcc -mmos6502:nes`（マッパー30）。`make` で `build/gunma.nes`。
- 中身: GB版（6面版）の遊び方とバランスをそのまま移植した。距離の計算はGB版と同じ「1マス=8」の単位で行い、画面には2倍の大きさで描く。
- マップ: 16x12マス（1マス=16x16ドット）。色を16x16ドット単位で決めるため、マップは偶数行から始めている。6面とも道をこの大きさに合わせて引き直した。
- 敵: 1体を8x8のスプライト4枚で描く。1ラインに並べられるのは8枚までなので、毎フレーム表示の順番を入れ替え、ちらつかせて全員見せる。
- ROMの容量: 絵と文字のデータは固定バンク(16KB)に入りきらないため、バンク1に置いて起動時に切り替えている。プログラムと音は固定バンク。
- 難易度: `test/sim_nes.py` で新しいマップを確かめた。でたらめに置いたときのクリア率は栃木100%、東京40%（GB版の東京は42%）。何も置かなければ全面負け、うまく置けば全面クリア。
- 画面の確認: FCEUXの `savescreenshotas` は灰色の画像しか保存しなかったので、`test/lib.lua` の `snap()` で画素を読んで保存している。
