# グンマー教の野望 ファミコン版 仕様書 v1（GB企画）

## 方針
- 中身はGB版（6面版・17:51）と同じ。ルール、ユニット、敵、6面の順番、難易度、エンディング、注意書きはGB版 gb-gunma/docs/SPEC.md に従う。
- ここに書くのはファミコン版で変わる点だけ。

## 1. 画面（256x240 = 32x30タイル）
- 上2行: HUD（おかね / ライフ / ウェーブ / 地名）。
- 中央 32x24: マップ。1マス＝16x16（2x2タイル）にして、色の単位（16x16）とそろえる。マップは16x12マス。
- 下4行: ユニット名、コスト、メッセージ。
- NTSCでは上下8ドットが見切れることがあるので、上下1行ずつは何も置かない。

## 2. 色（BGパレット4組・各4色）
| 組 | 用途 | 色の目安 |
|---|---|---|
| 0 | 草地・木・山 | 黒 / 濃い緑 / 緑 / 黄緑 |
| 1 | 道・砂浜・ビル | 黒 / 茶 / ベージュ / 白 |
| 2 | 川・海 | 黒 / 紺 / 青 / 水色 |
| 3 | ユニット・町・HUD | 黒 / 赤 / オレンジ / 白 |
- スプライトのパレット4組: 敵（紫系＝グンマー教）、ボス（赤＋金）、弾・風（白・水色）、カーソル（黄）。

## 3. スプライト
- 敵は16x16（8x16を2つ）。1ラインに8個までなので、横に4体並ぶと上限。
- 同時に出る敵は最大8体のまま。横に詰まったときはGB版と同じく表示順を入れ替えてちらつかせる。
- 弾は最大8個まで。

## 4. 操作
GB版と同じ（十字、A、B、SELECT、START）。ファミコンのボタン配置も同じなので変更なし。

## 5. 音
- ファミコンの音源は矩形波2ch、三角波1ch、ノイズ1ch、DPCM。
- GB版の曲を移植。メロディ＝矩形波1、ハモリ＝矩形波2、ベース＝三角波、効果音の発射と撃破＝ノイズ、ほかの効果音は矩形波2を一時的に借りる。
- 曲・ジングル・効果音のリストはGB版と同じ。

## 6. 追加点（ファミコンらしさ・容量に余裕があれば）
- タイトル画面をカラーの一枚絵にする（グンマー帝国の城と関東の地図）。
- エンディングの文の下に、救った6つの地名を並べて表示する。

## 7. 完成条件
- FCEUXで注意書き → タイトル → 6面 → エンディング → タイトルまで通して遊べる。
- 色が16x16単位でくずれていない。
- 敵8体でもゲームが止まらない。
