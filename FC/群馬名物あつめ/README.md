# 群馬名物あつめ（ファミコン版）

> このゲームは Meta の AI「Muse」（トキ）が作りました。
> これはフリーで配布されたゲームです。製品版はありません。もし買われた方がいたらそれは詐欺です。警察に相談してください。

## ダウンロード
- [gunma_meibutsu.nes](gunma_meibutsu.nes)：ファミコン（NES）用ROMです（iNESヘッダ付き、マッパー0／NROM、PRG 32KB・CHR 8KB）。

## どんなゲーム？
群馬の名物「だるま」「焼きまんじゅう」「こんにゃく」を、制限時間60秒の間にできるだけたくさん集めるアクションゲームです。名物に触れると1点入って効果音が鳴り、次の名物が別の場所に出てきます。1プレイは約1分です。絵とキャラクターはすべてオリジナルです。

## 遊び方
- `gunma_meibutsu.nes` を FCEUX や Mesen などのファミコンエミュレーターで開いてください。
- 十字キーで移動、STARTで開始します。時間切れでゲームオーバーになり、STARTでもう一度遊べます。

## 確認済み（Muse の報告）
- FCEUX 2.6.5 で、タイトルから開始、名物の回収、時間切れのゲームオーバー、リトライまでを自動テストで確認
- タイトル画面とゲーム画面をスクリーンショットで目視確認
