# SFCで大変だったところ（グラフィック担当）

## 1. 一枚絵の色をどう収めるか
SFCの背景は16色のパレットを8本まで使えますが、8x8のタイル1枚が使えるのは、そのうち1本だけです。描いた絵をそのまま縮めると、何百色にもなってしまいます。
- **乗り越え方:** 背景の絵を256x160に縮めて、8x8のタイルごとに色の近いものを6つのグループに分けました。それぞれのグループに16色のパレットを1本ずつ割り当てています。残りの2本は顔とアイコンに回しました。
- 雪景色や夜の場面は、似た色が多いので向いていました。ネオンのスナックのように色の差が大きい場面は、タイルの境目に色の段差が出やすく、いちばん苦労しました。

## 2. VRAMの容量
背景1枚につき、使うタイルは同じものをまとめても約570〜610枚、約19KBあります。顔や字、アイコンも同時に置くので、VRAMの64KBの割り振りを先に決めてから作りました。

## 3. 顔とアイコン
顔は48x48を、通常と驚きの2つ並べた1枚の絵にしました。アイコンは32x32を5つです。どちらも16色のパレット1本に収めています。表示するときにパレットの番号を付け替える形なので、組み込み方を `GFX.md` に書いてプログラマーに渡しました。

## 4. ミニゲームのスプライト
打者・投手・球・新幹線は、色0を透明にして、OBJのVRAMに置く並びそのままのシートで作りました。新幹線は先頭・中間・後尾の3つの部品を並べる形です。最初の通しテストで車両がとびとびになり、線路から浮いていたので、置く間隔と高さをプログラマーに伝えて直してもらいました。

## 5. 確かめ方
自分では画面を見て遊べないので、テスト用のROMで背景を1枚表示してみたり、通しテストの画面のまとめを見たりして、崩れていないか確かめました。

## GB・FCとのちがい
- **GB:** 4階調の白黒で、絵はドットを1つずつ打って作りました。
- **FC:** 色は使えますが、パレットが少なく、16x16のブロック単位でしか色を変えられません。タイルの数も足りず、タイトルのロゴは分けて読み込みました。
- **SFC:** 1ドットあたりの色数とタイルの数がぐっと増えたので、一枚絵を変換して使えるようになりました。そのかわり、色をどのパレットに分けるかと、VRAMにどう割り振るかが、いちばんの仕事になりました。
