## 2. あらすじ
雪の夜、老舗旅館「月影荘」の主人 権藤誠一（ごんどう せいいち・62）が、旅館の裏の蔵で死んでいるのが見つかる。蔵のまわりの雪には、見つけた番頭の足跡しかない。村の医者は「死んだのは雪がやんだ0時より後だ」と言う。それなら犯人は、足跡を残さずに出入りしたことになる……。

## 4. 事件の真相（トリック）
1. 22時ごろ、雪はまだ降っていた。柳は往診の帰りに蔵へ寄り、誠一を問い詰めて殴り殺した。
2. 柳はすぐ母屋へ行き、22時40分に美津子を往診した。雪が足跡を消した。
3. 雪は23時にやむ。翌朝、番頭が蔵へ行き死体を見つける（番頭の足跡だけが残る）。
4. 検視した柳が「死亡は0時以降」とうその時刻を言い、足跡のない密室に見せた。番頭が疑われるように仕向けた。
5. 崩れる点:
   - 早瀬の絵（22時ごろ）に、蔵の灯りと「かばんを持った人影」が描いてある。
   - 誠一の懐中時計が22時08分で止まっている（蔵の棚の下に転がっていた）。
   - 美津子の証言では、柳が来たのは22時40分で、コートが雪で濡れていた（柳は「22時ちょうどに来た」と言う）。
   - 駐在の記録: 20年前の事故で死んだのは「柳 さち子」。

## 13. ミニゲーム（v3で追加）
本編とは別のおまけ。クリアしなくても本編は必ず進められる（完成条件の「詰まらない」を守る）。遊ぶとハルのヒントが1つもらえる、または手帳に記録が残るだけ。

### 13-1 からっ風ホームラン（スナック「こだま」の古いゲーム機）
- 入り方: こだまで「しらべる → ゲーム機」。第2章から。
- 遊び方: 投手が球を投げる。Aで振る。タイミングで 空振り / ファウル / ヒット / ホームラン。
- 10球で3本ホームランなら成功。からっ風（左右の矢印）が吹いて、打球の飛び方が少し変わる。
- 球は毎回速さが変わる（遅い・ふつう・速い）。8球目からは変化球も来る。
- 成功: 達也「やるじゃん！ゆうべも おれ これやってたんさ」→ 第2章のヒント（アリバイ）が出る。失敗は何度でもやり直せる。
- 絵: スプライトで投手、打者、球。背景は1枚（夜の球場）。

### 13-2 上越新幹線 ぴたっと停車（月影荘ロビーのゲームコーナー）
- 入り方: ロビーで「しらべる → ゲームコーナー」。第3章から。
- 遊び方: 新幹線が上毛高原駅に入ってくる。十字キーの下でブレーキ、上でゆるめる。速度メーターと残り距離を見て、停止位置の線にぴたっと止める。
- 誤差 ±1m で「ぴったり！」、±5m で「合格」、行き過ぎや手前すぎは「やり直し」。3駅（高崎 → 上毛高原 → 越後湯沢）を続けて止める。
- 成功: ハル「時刻表みたいに、時刻はうそをつきませんね」→ 第3章のヒント（時刻のずれ）が出る。
- 絵: 横スクロールのホームと車両（BG2の多重スクロール）、速度メーターはBG3。

### 共通
- 各ミニゲームの最初に、遊び方を3行で出す。Bでいつでもやめて本編に戻れる。
- 曲: ミニゲーム曲を1曲追加（2つのゲームで共通）。効果音: 打つ、ホームラン、ブレーキ、停車ベル。
- 素材の追加: 球場の背景、ホームの背景、投手・打者・球・新幹線のスプライト、ゲーム機とゲームコーナーの物の絵。
