# シナリオの書き方（GBプログラマー）

セリフとフラグは `scenario/script.txt` に1つのテキストで書きます。プログラムはこれをPythonで読み、使う字を拾い、ROM用のデータに変換します。字の拾い出しもこのファイルからするので、ここに書いた字だけが画面に出せます。

## 形
```
@場所 lobby  ロビー            ← 場所の定義（id、メニューに出る名前）。背景は bg_<id>
@人 mitsuko 美津子 lobby       ← 人物（id、名前、いる場所）。顔は face_<id>
@物 lobby tokei 柱時計          ← 場所 lobby の「しらべる」対象

#きく mitsuko ゆうべのこと  [条件: F_GENBA]  [立てる: F_OUSHIN]
ハル> 奥さん、ゆうべのことを聞かせてください。
mitsuko> 10じ40ぷんごろ、柳先生が 往診に来てくれたんさ。
mitsuko!> コートが 雪で ぬれてたっけね。      ← ! は驚きの顔
*> （手帳に 書きとめた）                   ← * は地の文

#しらべる kura_in tana [立てる: F_TOKEI] [証拠: tokei]
...
#みせる yanagi tokei [章: 5] [順番: 1]
#よぶ [章: 1]          ← ハルのヒント（章ごと、条件で複数可）
#章 2                  ← 章が変わるときのハルのまとめ
#はんにん mitsuko      ← まちがえたときのハルの止めゼリフ
#エンディング
```
- `[条件: A,B]` は全部そろっているときだけ出る。`[条件: !A]` はまだ立っていないとき。
- 1行は全角16字まで（窓の幅）。長い行は自動で折り返す。3行ごとに A 待ち。
- 同じ相手・同じ話題を2回目に聞いたときのセリフは `#きく ... [2回目]` で書けます（無ければ1回目をくり返す）。
- 章が進む条件（仕様書7章のフラグ）はプログラム側で持つので、ここでは立てるフラグだけ書けば大丈夫です。
