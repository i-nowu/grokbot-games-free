# SFC グラフィック仕様（GBグラフィック）
生成: `python3 tools/gfx/gen_gfx.py` → `res/gfx/<name>.pic/.map/.pal`, プレビュー `res/preview/`
- pic: SNES 4bpp (32B/tile)。map: 16bit `tile | pal<<10`。pal: BGR555 LE。
## 背景 bg_*（10枚）
256x160 = 32x20 tiles、パレット0〜5（6本x16色、色0=黒）。ユニークタイル約570〜610（〜19KB）。BG1 Mode1、SC_32x32でそのまま可（上20行）。
## 顔 f_*（9人）
96x48 = 12x6 tiles 行優先。左6列=通常、右6列=驚き。パレット1本。mapはpal=0なので、表示時に `pal<<10` を差し替え（例: 6）。
## アイコン icons
160x32 = 20x4 tiles、32x32を5個（時計/絵/借用書/鍵/記録）。パレット1本、map pal=0（差し替え要、例: 7）。
## 検証
`res/emu_check.png`: bg_lobby を snes9x で表示確認済み。
## ミニゲーム
- 背景 `bg_mg_stadium`（からっ風ホームラン）、`bg_mg_station`（ぴたっと停車、赤い停止線は x≈108〜140 / y≈114）。形式は他の背景と同じ。
- スプライト `spr_mg.pic/.pal`: 128x48 のシート = OBJ の VRAM 並び（16タイル/行）で96タイル、パレット1本（色0は透明）。
  - 打者 32x32: 構え(タイル0) スイング(4)
  - 投手 16x32（16x16を縦2つ）: 振りかぶり(8,40) 投げ(10,42)
  - 球 8x8: 大(12) 小(13) 影(14)
  - 新幹線 32x16 を横に並べる: 先頭(64) 中間(68,繰り返し) 後尾(72)
