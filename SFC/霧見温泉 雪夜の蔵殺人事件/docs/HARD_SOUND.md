# SFCで大変だったところ（音楽担当）

## 1. 音を作る仕組みがまったくちがう
GB・FCでは、音源のレジスタに「この高さで鳴らせ」と毎フレーム書き込む小さなドライバを自分で作りました。
SFCには音楽専用のCPU（SPC700）と64KBの音のメモリがあり、本体のCPUはデータを送るだけです。
PVSnesLibでは、Impulse Tracker形式（.it）の曲ファイルを変換ツールで音のデータにまとめます。

- **乗り越え方:** トラッカーソフトがないので、.itファイルを直接書き出すスクリプトを作りました。GB版と同じ「音名:長さ」の楽譜から、曲と効果音の.itを何度でも作り直せます。

## 2. 音色を自分で用意する
GB・FCは音源に矩形波や三角波が入っていますが、SFCは波形（サンプル）を自分で渡します。
- 矩形波、三角波、やわらかい音、ノイズを、短い波形としてプログラムで作りました。
- 効果音は1つずつ短い音として作り、効果音専用のファイルにまとめました。

## 3. 音のメモリの容量
効果音と、今鳴らしている1曲が、約58KBに収まる必要があります。
波形を短くし、効果音のサンプリングを8kHzにして、全部入れても40KB以上空くようにしました。

## 4. 耳で確かめられない
作業環境では音が聞けません。最初は、楽譜から直接作ったWAVで確かめていました。
でもROMから実際に録った音を数字で調べたら、音が鳴った直後にすぐ消えていました。
- **原因:** 楽器に「音量を保つ」設定（音量エンベロープ）がありませんでした。そのせいで、SFCの音源では音がのびませんでした。直接作ったWAVには、この問題が出ません。
- **乗り越え方:** 公式サンプルの曲と見比べて原因を見つけ、楽器に音量を保つ設定を入れました。録り直して、無音がなくなったことを確かめました。
- **教訓:** 本物の音源を通した音で確かめないと、わからない問題があります。

## GB・FCとのちがい
| | GB・FC | SFC |
|---|---|---|
| 鳴らし方 | 自作ドライバが毎フレーム書く | 音楽専用CPUに曲データを送る |
| 音色 | 音源に入っている | 波形を自分で作る |
| 同時に鳴る音 | 4〜5音 | 8音 |
| 確かめ方 | レジスタの値を読む | ROMの音を録って数字で調べる |
