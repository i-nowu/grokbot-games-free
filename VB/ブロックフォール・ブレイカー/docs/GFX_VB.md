# VB 絵の形式
- 色: 黒＋赤3段（0〜3）。キャラ8x8 2bpp（1行16bit、左端が下位ビット）。`res/vb_chars.bin`、並びは `res/vb_chars.txt`。
  - 0〜13: ブロック7種（明るい無地/縦じま/横じま中/枠/暗い点/市松/斜め中）、爆弾、鉄、パドル片、ボール、破片3種。
  - 14〜173: ステージ番号の数字0〜9（32x32、16キャラずつ）。
- 確認: `res/preview/vb_tiles_x4.png`、`res/preview/vb_blocks_x8.png`、ステージクリア演出のラフ（左右の目、ずれ+4→0）`res/preview/vb_stageclear_frames.png`。
- 生成: `tools/gfx/gen_vb.py`。
- ステージクリア演出のルール（企画指示）:
  - 1コマ目は破片だけ（数字なし、余白ルールなし）で、ブロックがはじける様子を見せる。2コマ目から数字を出す。
  - ステージ番号は最前面のワールド（いちばん最後に描く＝優先度最高）に置く。破片はそれより奥のワールド／OBJ。
  - 数字の箱（32x32）の上下左右1マス（8px）は、2コマ目以降は破片を入れない。入りそうな破片はそらすか消す（ラフでは消している）。左右の目それぞれで、その目のずれを入れた位置で判定する。
- 本番の盤面スプライト＋左背景（`tools/gfx/gen_vb_sprites.py`）: `res/vb_chars2.bin` 25キャラ400B、並びは `res/vb_chars2.txt`。
  - CH_ART+174 = キャラ430 から置く想定（既存0〜173の並びは変えない、512の仮の絵の前に収まる）。
  - 0〜16は仮の絵（res_ph.c の ph_chr）と同じ並び: 0壁 1〜8敵（カニ/おばけ/目玉/コウモリ×2コマ）9〜12ボス16x16（左上,右上,左下,右下）13爆発 14ひび鉄（鉄キャラ8＋黒いひび）15星 16UFO。
  - 17〜24: 左背景（17空、18〜21 暗赤の点線ひし形格子16x16、22・23小さな星、24予備）。
  - `res/vb_bgleft.map`: BGMap 0（M_BG）の左18列x28行。u16 LE 行優先、値は絶対キャラ番号（430〜）。BGMap では map[y*64+x]。説明文（2,22）（2,24）の周り＝行21〜25・列1〜17は空にして読みやすくしている。
  - 組込み: `vb_chars2.bin` を CHR 430 に読み込み、`CH_PH` を 430 にする（ltile の割当てはそのまま使える）。game_screen の `stars(M_BG,1,0,18,3)` は `vb_bgleft.map` のコピーに置き換える。奥行きはいまの M_BG ワールド（31、GP+2＝奥）のままでよい。ステージクリア演出のルールは変更なし。
  - 確認: `res/preview/vb_sprites2_x4.png`、プレイ画面モック `res/preview/vb_play_mock_x4.png`。
