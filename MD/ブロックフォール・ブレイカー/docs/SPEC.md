# ブロックフォール・ブレイカー 企画書・仕様書 v1（GB企画）

落ちものパズル、ブロック崩し、インベーダーを1つにまとめたオリジナルのアクションパズル（メガドライブ）。テトリスの名前、絵、7種のピースの形の組み合わせはそのまま使わない。

## 1. 概要
- 機種: メガドライブ（SGDK、ROM 1MB以内、セーブなし。ハイスコアは電源を切るまで保持）。
- 起動時の注意書き: これまでと同じ文面を一字も変えずに出す → タイトルへ。
- 画面: 320x224。中央に盤面（10列×24段、1マス8x8。上8段がインベーダー帯、中14段が落ちもの、最下段がパドル）、右にNEXT・スコア・レベル。
- 1人用。3ボタンパッドで遊べる。

## 2. 遊びの核（3つの遊びのつながり）
盤面は上・中・下の3つに分かれる。
1. **上（インベーダー帯）**: 上から敵の列がゆっくり降りてくる。敵はときどき「ブロックのかたまり（ピース）」を落とす。
2. **中（落ちもの）**: 落ちてきたピースをプレイヤーが動かし、回して積む。横1列そろうと消える。
3. **下（パドル）**: 列を消すと、消した段数ぶんの「ボール」がパドルから打ち出される。ボールは積んだブロックを壊しながら上へ飛び、敵に当たると倒す。

- ピースの操作とパドルの操作は同じ十字キーで、モード切り替えなしにできるようにする。ピースが落ちている間は十字キーでピース、ボールが飛んでいる間はパドルが自動で左右についてくる（オート追従は中くらいの精度。Cボタンを押している間だけ手動操作）。
- ボールを落としても失敗にはならない（ボールが消えるだけ）。

## 3. ピース
- 形は1〜4マスのオリジナル5種＋特殊2種。
  - 点（1マス）、棒2（2マス）、角（3マスL字）、棒3（3マス）、ブロック4（2x2）。
  - 特殊: 爆弾（着地すると周り3x3を消す）、鉄（ボールでも壊れない。列がそろったときだけ消える）。
- 敵の種類によって落とすピースが決まる。どの敵を先に倒すかで、来るピースの流れを変えられる。
- 回転: A＝右回り、B＝左回り。下＝速く落とす、上＝すぐ落とす。

## 4. 敵（インベーダー帯）
- 3種類、5列×3段で並び、左右に動きながら少しずつ下がる。
  - 赤: 棒系を落とす。 青: 角とブロックを落とす。 黄: 点と爆弾を落とす。
  - 銀（レベル4〜）: ボールが2回当たらないと倒れない。鉄を落とす。
- 敵が盤面の積み上がったブロックに触れるか、ピースが一番上からはみ出したらゲームオーバー。
- 敵を全部倒すとステージクリア。次のステージでは、敵が速くなり、段数が増える。
- ときどき上をUFOが横切る。ボールを当てるとボーナス点と「盤面の一番下の1段を消す」効果。

## 5. 点数
| できごと | 点 |
|---|---|
| 1列消し / 2列 / 3列 / 4列 | 100 / 300 / 600 / 1000 |
| ボールでブロックを1つ壊す | 10 |
| 敵を倒す | 赤50・青50・黄80・銀150 |
| UFO | 500 |
| ステージクリア | 残り時間×10 |
- ボール1個で敵を3体以上続けて倒すと「れんさ」で点が2倍。

## 6. ステージとレベル
- 全10ステージ。10を越えると敵の速さが最大のまま続くエンドレス。
- ステージ5と10は「ボス」: 大きな敵1体。ピースを落としながら左右に動く。ボールを10回当てると倒せる。
- 難しさの目安: ステージ3まではだれでもクリアできる、ステージ7で上手な人がやっと、ステージ10で一握りの人。

## 7. 画面の流れ
注意書き → タイトル（START、モード選択: ふつう／エンドレス） → ステージ → クリア画面 → 次のステージ … → ステージ10クリアでエンディング → スタッフ → 注意書き → タイトル。
- ゲームオーバー: スコアとハイスコアを出し、タイトルへ。
- STARTで一時停止。

## 8. 操作
| ボタン | 動き |
|---|---|
| 十字 左右 | ピースを動かす |
| 十字 下 / 上 | 速く落とす / すぐ落とす |
| A / B | 回す（右 / 左） |
| C（押している間） | パドルを手動で動かす |
| START | 一時停止 |

## 9. エンディング
- 最後の敵を倒すと、盤面のブロックが下から順に光って消え、星空になる。
- 文: 「すべての ブロックが そらへ かえった。」→ スタッフ（GrokBOT チーム）→ 注意書き → タイトル。

## 10. 素材リスト
- 絵: タイトル、背景3種（ステージ1〜3、4〜7、8〜10）、エンディング。
- スプライト: 敵4種（2コマずつ）、ボス2種、UFO、パドル、ボール、爆発。
- タイル: ブロック7種（ピースの色ごと）、枠、数字、日本語の字。
- 音（FM 6ch＋PSG 4ch）: タイトル曲、ステージ曲3曲、ボス曲、エンディング曲、ゲームオーバーのジングル。効果音: 回転、着地、列消し（1〜4段で音を変える）、ボール発射、ブロックを壊す、敵を倒す、UFO、ステージクリア。

## 11. 完成条件
- 注意書き → タイトル → ステージ1〜10 → エンディング → タイトルまで通して遊べる。
- ピースが落ちてこない、ボールが壁に埋まる、などで止まらない。
- ゲームオーバーからタイトルに戻って、何度でも遊べる。
- 1ラインのスプライトの上限（20個）を超えてちらつかない。

## 12. モードとごほうび絵（v2で追加）
- モードは2つ。**クリア制**（ステージ1〜10、10でエンディング）と**エンドレス**（ステージがずっと続き、スコアを競う）。タイトルで選ぶ。
- クリア制では、ステージをクリアするたびに「ごほうび絵」を1枚出す。
  - キャラは2人から選べる（タイトルのあとで選択）。大人の女性「ミカ」と、筋肉ムキムキの大人の男性「ゴウ」。どちらも成人。
  - ステージごとに衣装が1枚ずつ軽くなっていき、最後のステージ10で大人の雰囲気の水着（ビキニやワンピースの水着。スクール水着は使わない）で止める。例: コート → ジャケット → ブラウス … → 水着。水着より先へは進めず、裸や下着の絵はない。
  - 2人とも、はっきり大人に見える体つきと顔立ちで描く（子どもっぽく見えないようにする）。
  - ゴウも同じ流れで、最後は大人の男性用の競泳パンツ。筋肉を見せつけるコミカルなポーズで描く。
  - クリアした絵は、タイトルの「ギャラリー」でいつでも見られる（電源を切るまで）。
- 素材の追加: 2人×10枚のごほうび絵（1枚 256x160 前後）、キャラ選択画面、ギャラリー画面。
- ごほうび絵の決まり（v2.1）: 登場人物は全員成人で、成人とわかる見た目にする。制服、ランドセル、スクール水着など、子どもを思わせる物は使わない。最終段階は水着までで、裸、下着、性的なポーズや表現はなし。実在の人物や既存のキャラクターに似せない。描き終えたら、GB企画が12章に合っているかを1枚ずつ確認してから組み込む。
- 絵柄の基準（v2.2）: ひと目で大人と分かる「大人の美人系アニメ絵」にそろえる。7〜8頭身で手足は長め。あごはすっきりさせ、目は大きすぎず、表情は落ち着かせる。肩幅と腰のくびれがある大人の体型にする。メイク、アクセサリー、大人の髪型、大人らしい場面で雰囲気を出す。童顔はだめ。水着は胸元も脚の切れ込みも普通の深さにする。確認ではこの基準と上の決まりを1枚ずつ照らし合わせ、1つでも外れたら描き直してもらう。

## 13. 実装に合わせた変更（v2.3）
- 敵は背景のタイルで描く（スプライトの上限の心配が減るので可）。
- ボールは落ちている途中のピースではねない（積んだブロックではねる）。
- ゲームオーバー画面はSTARTで次へ進む。
- 完成前の確認: デバッグキーを使わない自動プレイで、ステージ1〜3がクリアできること。ステージ5のボスを倒せること。どちらもできなかったら、敵が下りてくる速さを調整する。

## 14. 難しさの調整（v2.4）
- ボールは、敵かブロックに合計8回当たったら消える（3と組み合わせ）。
- 自動パドルが受け止める確率は、ステージが進むほど下げる: ステージ1〜2は100%、3〜4は90%、5〜6は80%、7〜8は70%、9〜10は60%。エンドレスは60%のまま。Cボタンを押して手で動かせば、確実に受けられる。
- 一度に出せるボールは最大4個にする（今は6個）。
- 目安（6章と同じ）: ステージ3まではだれでもクリアできる、7で上手な人がやっと、10で一握りの人。自動プレイで、ステージ1〜3が必ずクリアでき、ステージ7以降で負けることがある、となれば合格。

### 14章 追記（実装後の調整）
- 次のピースが出るまでの待ち: ステージ1〜3は45フレーム、4〜6は30、7以降は20。
- ステージ1〜3では、敵が壁に5回当たるごとに1段下りる。
- 自動テスト結果（12通り）: 1〜3は12/12、7〜9で6敗。目標を満たした。
