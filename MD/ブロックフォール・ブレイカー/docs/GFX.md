# グラフィック（メガドライブ）

## パレットの割り当て
| パレット | 使い道 |
|---|---|
| PAL0 | 背景の絵（タイトル、ステージ背景3種、エンディング） |
| PAL1 | ブロック7色、枠、UI、数字 |
| PAL2 | スプライト（敵、UFO、パドル、ボール、爆発）。ごほうび絵もここ（PROGRAMMING.md） |
| PAL3 | 日本語フォント、ボス |

色は 9bit（1色あたり 0,36,73,109,146,182,219,255 の8段）です。

## ごほうび絵
- 元の絵: `res/src/mika01〜10.jpg` `gou01〜10.jpg`（GB企画の確認済み）
- 出力: `game/res/reward/mika01〜10.png` `gou01〜10.png`。256x160、4bpp インデックス、1枚に16色。色0がいちばん暗い色です。
- 作り直し: `python3 tools/gfx/conv_md.py`（1枚だけなら `python3 tools/gfx/conv_md.py mika03`）
- 中央を16:10で切り抜いて縮め、色を9bitに合わせて16色に減らし、軽くディザをかけます。
- mika03・mika05 の看板にあった偽の文字は、ぼかして消しています（座標は conv_md.py の `SIGNS`）。
- 確認: `res/preview_reward16.png`（20枚の一覧）。固有タイルは1枚あたり558〜640枚です（上限は700枚）。

## 一枚絵（game/res/gfx/）
`python3 tools/gfx/conv_md.py bg1 bg2 bg3 ending title face_mika face_gou`（元画像と切り抜きは conv_md.py の `JOBS`）。
どれも 16色・4bpp、色0は真っ黒です（画面の背景色が黒なので、透明でも黒く見えます）。
320x224 の絵は、固有タイルが700枚を超えないように、似たタイルをまとめています（680枚まで）。bg1・bg3・ending はディザなしです。
