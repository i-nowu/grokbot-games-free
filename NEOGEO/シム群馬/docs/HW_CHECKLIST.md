# 実機で確かめること— シム群馬 final-wip1

- 対象: 配布版 simgunma.zip（md5 5318fc5efa45f296e4cac1b5b3da17f0）。ここまでの結果はすべて MAME 0.276 でのもので、**実機未確認**です。
- 書き方: 各項目に「結果（○／×／未）」「日付」「本体（AES／MVS の型番）」「確かめた人」「メモ」を書き足してください。

## 1. 起動・注意書き
- [ ] 起動のときの注意書きが、文も位置も MAME と同じに出る（文はこの版でも変えていない）
- [ ] 注意書きの間、パレット8〜12 が25%に暗くなり、消えたあとに元に戻る（下の「絵」も見る）
- [ ] 電源を入れたときの音の初期化（0x03 → 0x83 の返事）が通り、タイトルの曲が鳴る。ソフトリセットでは送り直さない
- [ ] ウォッチドッグでリセットがかからない（長いループ、セーブ、ダービーの出入り）

## 2. メモリーカードのセーブ（AES／MVS）
- [ ] 月を終えたときの自動保存。保存した月だけ、右下に小さな知らせが60フレーム出る
- [ ] カードがないとき・書きこみ禁止のとき・いっぱいのときの知らせ
- [ ] 「つづきから」で読みこみ、こわれたデータを正しくはじく
- [ ] BIOS のカード画面にデータの題名「SIMGUNMA」が出る
- [ ] ダービーの人口はセーブに入らない（新しいゲームで0）

## 3. MVS のクレジット
- [ ] コインでクレジットが増え、コインの音 0x6A が鳴る（デモ画面の音が「なし」でも鳴る）
- [ ] INSERT COIN／PRESS START／FREE PLAY の表示（本体DIPのフリープレイも）
- [ ] 1クレジットの年数（ソフトDIP）とコンティニュー
- [ ] MONTH TIME（60／30／90秒／無制限）と、時間切れのときの自動の「月を終える」
- [ ] デモ画面の音「なし」のとき、0x73／0x74 で音が止まり・戻る
- [ ] ランキングの記録が電源を切っても残る（バックアップRAM）

## 4. AES の B+START（ダービーだけ遊ぶ）
- [ ] AES のタイトルで B を押しながら START でダービーに入る。B だけでは入らない
- [ ] A を押すとふつうのゲームが始まる（ダービーに入らない）
- [ ] 終わってタイトルに戻り、予算・乱数の種は変わらない
- [ ] MVS では入らない
- [ ] AES では $D00000〜$D0FFFF をゲームが読まない（MAME では final-wip1 で確かめた。読むのは BIOS だけ）

## 5. 音（ヒビキさんから）
- [ ] ダービーの3つの音（0x6F 打つ、0x75 投げる、0x76 歓声）の大きさと音割れ
- [ ] 効果音が鳴ったときに、曲が1フレーム遅れること（耳でわかるか）
- [ ] 全体の音量（0x78〜0x7F）の聞こえ方
- [ ] 0x75 → 0x6F → 0x76 の鳴り始めのずれ（MAME の録音と比べる）
- [ ] 曲の返事が来ないときの送り直し（1回だけ）が、実機の Z80 でも同じに動く

## 6. 絵（ツムギさんから）
- [ ] タイトル、顔、ダービーの絵の色が、MAME と比べて変わっていないか（とくに暗い色と肌の色）
- [ ] ダービーの背景（スプライト67〜86、パレット18）と選手（160〜）が、ちらついたり欠けたりしていないか
- [ ] 注意画面でパレットを暗くしたときと、もとに戻したときの見え方
- [ ] FIX の文字（S1）が、いつもスプライトより上に出る

- FIXの文字が、顔やダービーのスプライトより上に出ること

## 7. 1ラインのスプライトの数
- [ ] いちばん多い場面で欠けがない。MAME では、本編が全体66本・1ライン47本（地図、ミナトさんが毎フレーム数えた値）、ダービーが全体25本・1ライン23本（計算）。上限は1ライン96本、全体380本
- [ ] 地図をスクロールしたときと、顔の窓が出たときに欠けやちらつきがない

## 8. パレット
- [ ] パレット13〜18 の色（顔、枠、ダービー、ダービーの背景）
- [ ] 背景色（$400FFE、黒）と、色0の透明
- [ ] 画面を替えたときに、前の画面の色が残らない（とくにダービーを出たあと）

## 9. そのほか、エミュレータでは確かめられないこと
- [ ] 本物の BIOS（AES／MVS、国ごと）での動き。MAME の試験は主に 開発用BIOS とテスト用 BIOS
- [ ] ブラウン管と液晶での見え方。にじみ、オーバースキャンで画面のはしが切れないか
- [ ] コントローラーの入力（チャタリング、同時押し、2P側）
- [ ] 長い時間遊んだとき（数時間）に止まったり、おかしくなったりしないか
- [ ] 電源の入れ直し、コインを入れる途中の電源断、カードの抜き差しのときの動き
- [ ] 本体の DIP スイッチ（MVS）と、テストモード
- [ ] 実際のカートリッジに書いたときの ROM のビットの並び（C1／C2 の対、P1 のバイトの並び）

- AESで、ゲームが $D00000〜$D0FFFF を読まないこと（BIOSが読むのは別）
