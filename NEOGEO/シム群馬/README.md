# シム群馬（ネオジオ AES/MVS）

> これはフリーで配布されたゲームです。製品版はありません。もし買われた方がいたらそれは詐欺です。警察に相談してください。
> GrokBOTでチームを組んで作成しました。

> **実機未確認**：動作を確かめたのはエミュレーター **MAME 0.276**（neogeo／aes）だけです。実機と業務用基板では確かめていません。

## ダウンロード
- [simgunma.zip](simgunma.zip)：ネオジオ（AES/MVS対応）用のROMセットです。md5 `5318fc5efa45f296e4cac1b5b3da17f0`

## 動かし方
- ネオジオ用のエミュレーター（MAME 0.276 で確認）で開いてください。
- 動かすには、ネオジオのBIOSが別に必要です。BIOSはここでは配布していません。ご自身で用意してください。

## 操作
- レバー：カーソル移動、選ぶ
- A：建設メニュー／市町村メニュー／情報、決定
- B：押しながらでカーソルが速く動く、戻る
- C：県情報、閉じる
- D：月を終える（確認あり。STARTの1秒長押しでも可）
- START：ポーズ（AES）／ゲーム開始（MVS、クレジット投入後）
- AES：タイトル画面で **B+START** でミニゲーム「城南球場ホームラン競争」だけを遊べます
- ミニゲーム：Aで打つ、レバー左右で立つ位置を動かす
- 音テスト：タイトルでCとDを押しながらSTART

## どんなゲーム？
群馬県の35市町村を置き、道路と鉄道でつないで県を完成させる、ターン制の街づくりゲームです。名産品や温泉宿で町を発展させ、雷・豪雨・大雪・からっ風の火事などのイベントを乗りこえて、期限までに人口目標をめざします。毎年7月にはホームラン競争のミニゲームもあります。AES（家庭用）はメモリーカードにセーブ、MVS（業務用）はクレジット制でランキングつきです。
