# サウンド（霧見温泉 NGPC）— GB音楽

900H 側は共有RAMに指令を書くだけで、音源の操作はすべて Z80 が行う。

## 組み込み方（GBプログラマー向け）
1. 起動時に1回 `call snd_init`。毎フレーム（VBlank のあと）1回 `call snd_update`。
2. SFC版の `bgm(MOD_xxx)` は `ld a,MOD番号` / `call bgm_play`、`se(n)` は `ld a,n` / `call sfx_play` にそのまま置きかえる。
   SFC版で曲を切り替えるたびにしていた `spcStop / spcLoad / spcLoadEffect` にあたる処理は要らない。
   `bgm_play` は前の曲を止めてから頭から鳴らす。同じ曲で呼んでも頭からになる（SFC版と同じ。SFC版は `curbgm` で同じ曲を呼ばないようにしている）。

## API（番号は SFC版と同じ）
| ルーチン | 入力 | 出力 |
|---|---|---|
| `snd_init` | なし | なし |
| `snd_update` | なし | なし |
| `bgm_play` | A=曲番号 1〜6（下の表）。0、7以上、0FFh（MOD_NONE）は停止 | なし |
| `bgm_stop` | なし | なし |
| `sfx_play` | A=効果音番号 0〜9（下の表）。10以上は無視 | なし |
| `bgm_playing` | なし | A=1/0、Z=0 なら再生中 |
| `sfx_playing` | なし | A=1/0、Z=0 なら鳴動中 |

- レジスタ：A 以外は保存。**フラグは壊れる**。
- `bgm_play` 直後の `bgm_playing` は、Z80 がまだ受け取っていなくても 1 を返す。
- 曲はすべてループする（SFC版の IT も最後の行で頭に戻る）。

効果音は SFC の 8kHz の波形を 1フレーム（16.7ms）ごとに区切り、各区切りの大きさ（RMS）と、設計値の音の高さを表にした。

## 使うメモリ
- **共有RAM 7000h-7FFFh（4KB）は全部サウンドが使う。ゲーム側は読み書きしないこと。**（ババ抜きと同じ）
  - 7000h-7ECBh Z80 プログラムとデータ（3,788バイト）
  - 7F00h-7F08h 指令エリア（ババ抜きと同じ並び）：+0 フレーム数（snd_update が+1）、+1 曲指令、+2 曲指令の回数、+3 効果音指令、+4 効果音指令の回数、+5/+6 Z80 が受け取った回数、+7 曲再生中、+8 効果音鳴動中
  - 7F20h-7F7Fh Z80 の変数（**ババ抜きの 7E00h から移した**。曲データが大きくなったため）、7F80h-7FEFh Z80 のスタック
- I/O：`snd_init` が 0B8h=55h（音源 ON）、0B9h=0AAh→55h（Z80 リセット→起動）を書く。0BAh（Z80 NMI）、0BCh、Z80 割り込みは使わない。
- ROM：900H 側ルーチン約 0.1KB ＋ Z80 本体 3.7KB。

## ババ抜きのドライバから広げたところ
- 曲のパートを 2 → 4（矩形波 ch0/ch1/ch2 + ノイズ）にした。パートは「16バイトのトラック」4本で同じ処理。
- テンポ：ババ抜きは GB のフレーム数で進んだが、SFC は「行」で進むので、16bit の積算（曲ごとの `K`=65536/(1行の秒×59.95)）で 1フレームに1行未満ずつ進める。行の頭は最も近いフレームに来る（ゆれは最大 1フレーム）。
- 音符の終わり（IT の note off）：1フレームに 8dB ずつ下げて、3フレームで消える。
- 効果音：矩形波の効果音は ch2、ノイズの効果音は ノイズを借りる。鳴り終わると曲のパートがすぐ戻る。

## チャンネルの割り当てと、SFC版との違い（妥協点）
| SFC（IT の楽器） | NGP（T6W28） | 違い |
|---|---|---|
| 1 lead（矩形波 25%） | 矩形 ch0 | T6W28 は 50% だけ。音色が少し丸く太くなる |
| 2 bass（三角波） | 矩形 ch1、**全体を1オクターブ上** | T6W28 の矩形波は 93.8Hz より低く出せない。SFC のベースは A1(55Hz)〜E3 で、6曲とも 93.8Hz より低い音がある。音の並びを崩さないよう、曲ごとにベース全体を上げた（6曲とも1オクターブ）。三角波→矩形波で音色も硬い |
| 3 pad（正弦波） | 矩形 ch2 | 音色が矩形波になる。効果音（0〜7, 9）が鳴っている間はパッドが止まる（タイトル・緊張・エンディング） |
| 4 hat（ノイズのサンプル 28ms） | ノイズ（白色、32kHz 刻み） | 2フレームで消える減衰表。ブレーキ（8）が鳴っている間はハイハットが止まる（ミニゲーム） |
| 効果音 3・9（正弦波） | 矩形 ch2 | 矩形波の音色になる |
| 効果音 2・6 | 1〜2フレーム | 15ms / 10ms の短い音は 1フレーム（16.7ms）に丸めた |

- 音量：IT のチャンネル音量 × 波形の大きさ（交流RMS）から、T6W28 の 2dB 刻みの減衰に丸めた。いちばん大きい効果音（矩形 振幅90）を減衰0とした。
- SFC 版は 8 ボイスで曲と効果音を同時に鳴らせるが、NGP は 4 チャンネルしかないので、上のとおり効果音がパッドかハイハットを一時的に止める。
- 左右とも同じ音量（SFC 版もパンは中央）。

## 測定（mednafen_ngp で録音、聴かずに数値だけ）
| 録音 | ピーク | クリップ | 音符の途中の 50ms 無音 |
|---|---|---|---|
| 曲 1〜6（各 1周以上） | 2254〜2949（-23.2〜-20.9dBFS） | 0 | 0（6曲とも） |
| 効果音 0〜9 | 300〜2502（文字送りが小さいのは SFC と同じ） | 0 | — |
| 曲＋効果音の重ね（タイトル＋決定・正解・ブレーキ・文字送り・まちがい） | 4922（-16.5dBFS） | 0 | — |
| 曲＋効果音の重ね（ミニゲーム＋ブレーキ・打つ・ホームラン・ベル） | 4271（-17.7dBFS） | 0 | — |
| 停止のあと（0.1s 以降） | 0 | — | — |

- 「音符の途中の 50ms 無音」は、譜面で lead/bass/pad のどれかが鳴っているはずの窓だけを数えた。捜査 35窓・ミニゲーム 25窓・対決 1窓の無音は、譜面ですべてのパートが切れている所（スタッカートの切れ目。SFC 実機の録音にも同じ周期で出る）。
- テンポ（メロディの音程の変わり目を打点にし、譜面の打点を時間方向に伸び縮みさせて重ねた比）：
| 曲 | NGP | SFC 実機録音 | 差（10秒あたりのずれ） | NGP 1周（自己相関） |
|---|---|---|---|---|
| タイトル | +1.86% | +1.76% | +0.10%（+10ms） | 19.552s |
| 捜査 | +1.82% | +1.82% | 0.00%（0ms） | 16.566s |
| 緊張 | +1.86% | +1.88% | -0.02%（-2ms） | 21.729s |
| 対決 | +1.90% | +1.80% | +0.10%（+10ms） | 10.868s |
| エンディング | +1.82% | +1.94% | -0.12%（-12ms） | 20.364s |
| ミニゲーム | +1.88% | +1.98% | -0.10%（-10ms） | 11.643s |

（% は IT の計算値に対する遅れ。測定の刻みは 0.02%。）
- 音程（左右とも同じ値）：lead A4 440.42Hz（+0.09%）、bass A2→A3 220.18Hz（+0.08%）、pad E4 330.39Hz（+0.23%）、決定 1046→1043.3Hz（-0.26%）/ 1568→1574.0Hz（+0.38%）、まちがい 220→220.3Hz / 165→164.95Hz、ベル 1318→1315.0Hz（-0.23%）。誤差は T6W28 の周期の刻み。
- 状態：曲再生中 7F07h=1、停止後 0。指令の回数と受け取った回数は一致（`peek` で確認）。

## 企画の判断が要るところ
1. ベースを6曲とも1オクターブ上げた（WS ぐんまと同じ方法）。別案：ババ抜きと同じ周期ノイズで元の高さを出す（音色は硬い）。ただしハイハットのある曲（捜査・対決・ミニゲーム）ではノイズがふさがっているので使えない。
2. 効果音が鳴っている間、パッド（タイトル・緊張・エンディング）またはハイハット（ミニゲームのブレーキ）が止まる。
3. テンポを SFC 実機の速さ（IT の計算より 1.86% 遅い）に合わせた。IT の計算どおりにも切り替えられる。
4. 音色はすべて矩形波（50%）。lead の 25%、三角波、正弦波、ノイズのサンプルの音色は出せない。
5. 文字送り・打つの短い音は 1フレームに丸めた。
