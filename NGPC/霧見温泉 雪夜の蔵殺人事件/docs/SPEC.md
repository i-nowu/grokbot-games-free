# 霧見温泉 雪夜の蔵殺人事件 NGPC版 仕様書（GB企画）

## 1. 方針
- SFC版の話・セリフ・人物・選択肢・フラグ・ミニゲームの中身をそのまま移す。変えない。
- 対象: ネオジオポケットカラー。asl(アセンブリ)、mednafen_ngpで確認。
- 毎フレーム `(6Fh)=4Eh` を書く。音はNGPババ抜きの音の仕組みを使い回す。

## 2. 画面（160x152 = 20x19）
- 上 20x11: 場面の絵（SFC版の絵を縮めて描き直す。NGPCの色の数に合わせる）。
- 中 1行: 場所名。
- 下 20x7: 文章（5行）と選択肢。文章は1行18字まで、ページ送りあり。
- 人物はみな大人とわかる見た目で、服は水着まで。SFC版にない絵は足さない。

## 3. 操作
| ボタン | 役割 |
|---|---|
| スティック | 選択肢を選ぶ |
| A | 決定、文章送り |
| B | 戻る |
| OPTION | ポーズ |

## 4. 合格条件
1. SFC版の全ルート（正解ルート、全ての間違い・ゲームオーバー、ミニゲーム）を、同じ選択の並びで通し、文章とフラグがSFC版と一致する。
2. 注意書きが一言一句同じ。
3. 曲と効果音がSFC版と同じ曲で、音割れ・途切れがない。
4. 20分遊んで止まらない・再起動しない。

## 5. 決定事項
- 新幹線ミニゲームの走り出し（開始時・結果画面を閉じた後）がSFC版より1フレーム早いのは、結果が同じなので認める。
- 注意文の余白は左右8px以上で可。
