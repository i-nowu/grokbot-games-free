# 霧見温泉 NGPC グラフィック（GBグラフィック）

SFC版にない絵は足していない。ご褒美の絵は SFC版に**ない**ので入れていない。

## 形式
- タイル 16B：1行=16bit LE、左端の点が bit15-14。
- 色 16bit LE：`0x0BGR`（各4bit）。パレット1本 = 4色×2B = 8B、要素0は透明（書いても無視）。

## タイル番号（512枚、BG/スプライト共用）
| 範囲 | 中身 |
|---|---|
| 0–15 | UI固定（0=透明の空白、`T_FILL`、窓枠 `T_WIN_TL,T,TR,L,R,BL,B,BR`、`T_PLACE_BAR`、`T_SOLID_LINE`）。12枚使用 |
| 126–445 | 場面ごとのタイル（2面合計で**最大320**、場面を変えるたびに読み直す） |
| 446–511 | スプライト66枚。通常：顔32（446-477）、アイコン16（478-493）、矢印2（494-495）。ミニゲーム中：`mg_spr_tiles.bin` 全体 |

| ファイル | 中身 |
|---|---|
| `scenes/<s>_tiles.bin` | 場面のタイル（タイル126から） |
| `scenes/<s>_map2.bin` / `_map1.bin` | 20x11 マップ。map2=SCR2（奥の面）、map1=SCR1（手前の面、0=透明） |
| `scenes/<s>_pal2.bin` / `_pal1.bin` | SCR2 用16本(128B) / SCR1 用15本(120B、パレット15は UI 用に空ける) |
| `scenes/<s>_bgc.bin` | 背景色（2B）。0x83E0 系の背景色レジスタへ（パレットの色番号ではなく直接色を書く場所に合わせて GBプログラマーさんが変換） |

## 画面（160x152）
- 行0–10：場面（SCR2 奥＋SCR1 手前）。顔は右下 x=128,y=56 の 32x32（2層スプライト32個）。アイコンは場面の真ん中など（SFC版は x=104,y=56）。
- 行11：場所名（SCR1、`T_PLACE_BAR` を敷いて x=1 から字）。行12–18：窓（枠＋5行×18字）。見本 `preview/mock_*_x4.png`。
- ミニゲームの停止線（ぴたっと停車）：SFC版 x≈108〜140/y≈114 は、NGPC版では **x≈68〜88 / y≈65**。スプライトは SFC の 0.625 倍（打者 24x24、投手 16x24、新幹線 24x16 ずつ）。

## 読み込み手順
1. 起動時：`ui_tiles` をタイル0から、`ui_pal` を SCR1 パレット15（0x8280+15*8）へ。矢印を タイル494 へ、`arrow_pal` をスプライトパレット12（0x8200+12*8）へ。
2. 場面を変えるとき（画面を消してから）：`<s>_tiles` をタイル126（0xA000+126*16）へ、`pal2`→0x8300、`pal1`→0x8280（120B）、`map2`→SCR2 の上11行、`map1`→SCR1 の上11行、背景色を設定。
3. 人が話すとき：`faces/<f>_pal` をスプライトパレット0〜7へ、表情の32タイルをタイル446へ、`_spr.bin` どおりにスプライト32個（x=128+dx, y=56+dy、層1を上に）。表情が変わったらタイル32枚だけ写し直す。
4. 証拠を見せるとき：アイコンの16タイルをタイル478へ（`icons_tiles`+番号*256B）、パレット8〜11。

## 顔の色合わせ
1人あたり使う色は約20色。8本×3色に収め、1マスは2本（6色）まで。収まらず近い色に置き換えた点（2表情 2048 点中）：haru 16、seiichi 17、mitsuko 19、tatsuya 21、sakaguchi 35、hayase 19、yanagi 23、yamauchi 62、mama 37。
