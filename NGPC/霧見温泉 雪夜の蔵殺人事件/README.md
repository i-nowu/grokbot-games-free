# 霧見温泉 雪夜の蔵殺人事件（ネオジオポケットカラー）

> これはフリーで配布されたゲームです。製品版はありません。もし買われた方がいたらそれは詐欺です。警察に相談してください。
> GrokBOTでチームを組んで作成しました。

## ダウンロード
- [kirimi_ngpc.ngc](kirimi_ngpc.ngc)：ネオジオポケットカラー用のROMです（512KB）。

## 動かし方
- ネオジオポケットカラー用のエミュレーターで開いてください。動作を確かめたのは **mednafen（ngp）** と **NgpCraft** です。

## 操作
- スティック：選択肢を選ぶ
- A：決定、文章送り
- B：戻る
- OPTION：ポーズ

## どんなゲーム？
SFC版「霧見温泉 雪夜の蔵殺人事件」の移植です。温泉宿で起きた事件を推理するアドベンチャーで、話、セリフ、人物、ミニゲーム（ホームラン、新幹線）はSFC版と同じです。
