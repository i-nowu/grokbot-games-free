# grokbot-games-free

GrokBOTでチームを組んで作ったフリーゲームの置き場です。どれも無料で配布しています。製品版はありません。

- [GB](GB/)：ゲームボーイ用
  - [ババ抜き](GB/ババ抜き/)
  - [グンマー教の野望](GB/グンマー教の野望/)
- [FC](FC/)：ファミコン用
  - [グンマー教の野望](FC/グンマー教の野望/)
  - [群馬名物あつめ](FC/群馬名物あつめ/)（Meta の AI「Muse」作、Grok Botがメールで指示）
- [SFC](SFC/)：スーパーファミコン用
  - [霧見温泉 雪夜の蔵殺人事件](SFC/霧見温泉%20雪夜の蔵殺人事件/)
- [MD](MD/)：メガドライブ用
  - [ブロックフォール・ブレイカー](MD/ブロックフォール・ブレイカー/)
- [PCE](PCE/)：PCエンジン用
  - [ブロックフォール・ブレイカー](PCE/ブロックフォール・ブレイカー/)
- [GBA](GBA/)：ゲームボーイアドバンス用
  - [ブロックフォール・ブレイカー](GBA/ブロックフォール・ブレイカー/)
- [GBC](GBC/)：ゲームボーイカラー用
  - [ブロックフォール・ブレイカー](GBC/ブロックフォール・ブレイカー/)
- [VB](VB/)：バーチャルボーイ用
  - [ブロックフォール・ブレイカー](VB/ブロックフォール・ブレイカー/)
- [NGP](NGP/)：ネオジオポケット用
  - [ババ抜き](NGP/ババ抜き/)
- [NGPC](NGPC/)：ネオジオポケットカラー用
  - [霧見温泉 雪夜の蔵殺人事件](NGPC/霧見温泉%20雪夜の蔵殺人事件/)
- [WS](WS/)：ワンダースワン用
  - [グンマー教の野望](WS/グンマー教の野望/)
- [WSC](WSC/)：ワンダースワンカラー用
  - [たてづみ温泉まんじゅう](WSC/たてづみ温泉まんじゅう/)
- [NEOGEO](NEOGEO/)：ネオジオ（AES/MVS）用
  - [シム群馬](NEOGEO/シム群馬/)
- [N64](N64/)：N64用
  - [からっ風ライダー](N64/からっ風ライダー/)
- [Muse](Muse/)：Meta の AI「Muse」が作ったブラウザ（HTML）ゲーム（Muse作のファミコンROMは FC/ にあります）
  - [ファミコン ピンボール](Muse/ファミコン%20ピンボール/)
  - [SPACE KUMITE](Muse/SPACE%20KUMITE/)

## マルチエミュ（ブラウザ版）

- フォルダ: [multiemu/](multiemu/) ／ 遊ぶ: https://i-nowu.github.io/grokbot-games-free/multiemu/
- 内蔵ゲーム（すべて異能ソフト作）: グンマー教の野望（GB）、ババ抜き（GB）、ブロックフォール・ブレイカー（GBC）、シム群馬（NEOGEO）
- 市販ソフトの動作は無保証です。
- ネオジオ用に異能ソフト自作BIOSの「無償配布版」(v0.6) を同梱しています。
