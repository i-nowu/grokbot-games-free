# PCエンジン用ご褒美絵の形式

変換ツール: `python3 tools/gfx/pce_conv.py .`（入力は256x160。出力先は `res/pce/`）

| ファイル | 中身 | 大きさ |
|---|---|---|
| `NAME_tiles.bin` | 640タイル。4bppのプレーン形式で1タイル32バイト。0〜15バイト目は行rごとに 2r=プレーン0、2r+1=プレーン1。16〜31バイト目はプレーン2と3を同じ並びで | 20480 B |
| `NAME_bat.bin` | 32x20のBAT。16ビットのリトルエンディアンで、値は `(パレット<<12) \| (0x400+n)` | 1280 B |
| `NAME_pal.bin` | パレット15本（BATの1〜15に対応）x 16色。16ビットのリトルエンディアンで、9ビットのGRB（`G<<6\|R<<3\|B`） | 480 B |

- 前提: タイルはVRAMのワードアドレス0x4000に読み込みます。タイル番号は0x4000/16 = 0x400 から始まります。ほかのアドレスに置くときは、BATのタイル番号をずらしてください。
- パレット0（文字用）は使いません。各パレットの0番は背景色で、絵の点には使いません。点は色1〜15だけを使います。
- 1枚のタイルは1本のパレットだけを使います。重複したタイルはまとめていないので、タイル番号は n = 行x32+列 の並びです。
- 確認用: `res/pce/preview/NAME_pce.png`（バイナリから元に戻した絵）と `all_x2.png`（一覧）
