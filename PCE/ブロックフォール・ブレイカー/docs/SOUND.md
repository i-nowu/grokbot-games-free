# 音（PCエンジン版）  GB音楽

MD版の曲7つと効果音11個を、PCエンジンの PSG（波形メモリ6ch）に編曲し直しました。メロディ、長さ、ループはMD版と同じです（楽譜はMD版の作曲スクリプトから写しています）。

## チャンネルの使い方
| ch | 役目 | 音色 |
|---|---|---|
| ch0 | メロディ（MD の FM1） | 31% パルス、少し減衰 |
| ch1 | ベース（MD の FM2） | 三角+矩形 |
| ch2 | 和音のパッド（MD の FM3） | やわらかいノコギリ、ゆっくり立ち上がる |
| ch3 | メロディのエコー（3/16拍遅れ、小さめのサイン波） | 新しく足した厚み。音の並びは ch0 と同じ |
| ch4 | ドラム（キック＝音程が下がる三角波、スネア・ハイハット＝ノイズ） | MD の PSG ノイズの代わり |
| ch5 | 効果音だけ（ノイズも使う） | 曲は ch5 を使いません |

## プログラマーさん向けの使い方
- ファイル: `common/snd.h`（番号と関数）、`common/snd.c`（ドライバー）、`res/sound/snd_data.h`（データ、自動生成）。
- 読み込む順番: `snd.h` → `snd_data.h` → `snd.c`（snd.c は自分では何も読み込みません。ビルド用の写しの置き場所に合わせてパスを書いてください）。
- 関数:
  - `snd_init()` … 起動時に1回。
  - `snd_update()` … 毎フレーム1回、`vsync()` のすぐ後。
  - `bgm_play(n)` … 曲を鳴らす（同じ曲を鳴らし中なら何もしない）。`n` は `BGM_TITLE` など（hw.h と同じ番号。0 は止める）。
  - `bgm_stop()` … 曲を止める。
  - `sfx_play(n)` … 効果音（`SE_ROTATE` など、hw.h と同じ番号）。ch5 だけで鳴り、前の効果音は打ち切ります。
  - `bgm_playing()` … 鳴っている曲の番号（終わったら0）。ゲームオーバーの曲は1回で終わるので、待つときに使えます。`sfx_playing()` も同様。
- 番号: BGM 1タイトル 2ステージ1 3ステージ2 4ステージ3 5ボス 6ゲームオーバー（ループなし） 7エンディング。SE 0回転 1発射 2〜5ライン消し1〜4 6撃破 7着地 8ブロック破壊 9UFO 10ステージクリア。
- 曲の切り替えは hw.c の `bgm()`、効果音は `se()` から呼ぶ形にすれば、ゲーム本体は変えずにすみます。今の hw.c の仮の効果音（`se_tick`）は ch5 を使うので、置き換えるときは片方だけにしてください。
- データは全部で約5.8KB（1本の配列）。HuCC はポインターの表を正しく作れないため、位置の表で引いています。

## 作り直し方と確認
- `python3 tools/snd/pce_compose.py` … データと試聴用 WAV（`test/sound/*.wav`、Python で PSG をまねたもの）。
- `tools/snd/build_sndtest.sh` … データを作り、サウンドテスト ROM（`sndtest/sndtest.pce`、I＝次の曲、II＝次の効果音、SELECT＝止める）をエミュレーターで鳴らして `test/sound/rom/` に録音し、音の大きさ・無音・音程を比べた表を出します。
- 楽譜: `tools/snd/pce_songs.py`（MD版の写し）。音色・ドラム・チャンネルの割り当ては `pce_compose.py`。

## 気をつけること
- 効果音は1chなので、ピークは曲全体（5ch）の約3分の1です（録音で効果音 約5400、曲 約18000）。小さいと感じたら、曲の音量を下げて合わせます。
- 試聴 WAV のノイズや音量はエミュレーターと少し違います。本当の音は ROM の録音で確かめてください。
