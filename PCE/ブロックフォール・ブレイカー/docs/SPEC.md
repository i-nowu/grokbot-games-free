# ブロックフォール・ブレイカー PCエンジン版 移植仕様 v1

元: /workspace/md-puzzle/docs/SPEC.md（MD版 最終版）。書いていないことはMD版と同じ。

## 1. 方針
- ゲームの中身、ステージ10面（5・10面ボス）、クリアモード／エンドレス／ギャラリー、難しさ（14章と追記）はMD版のまま。
- 媒体はHuCARD、ROMは1MB（8Mbit）。ご褒美の絵20枚で約430KBあるため。
- 起動時の注意文は一字一句同じ。1行に1文。フォントは美咲。
  「これはフリーで配布されたゲームです。製品版はありません。もし買われた方がいたらそれは詐欺です。警察に相談してください。GrokBOTでチームを組んで作成しました。」
- テトリスの名前と絵は使わない（MD版と同じ）。
- ソースコードは公開しない。アップロードは参謀がユーザーの許可を得てから行う。

## 2. 画面
- 解像度は256x224。MD版の320幅から詰める。
- 盤面は10列x24行のまま。右の情報欄（スコア、ハイスコア、ステージ、タイム、ライン、ネクスト、キャラ名）は幅を詰めて並べ直す。
- 敵はBGタイルで描く（MD版13章と同じ）。ボール、パドル、落下ピースはスプライト。
- スプライト上限: 1画面64個、横1ラインに16個。ボールは最大4個のまま。

## 3. 色
- BGは16色パレットx16本、スプライトも16色x16本。各パレットの0番は透明または背景色。
- MD版の絵は色数をそのまま移せる。PCEは512色なので、色はMDに近い値に合わせ直す。

## 4. 音
- PSGは波形メモリ6ch（5ビットx32サンプル）。5・6chはノイズも使える。
- MD版のXGM2曲を6chに編曲し直す。効果音は1chを効果音専用にして、曲と取り合わない。
- PCM（効果音の声など）は、使うなら直接出力で短いものだけにする。必須ではない。

## 5. 操作
- PCEのパッドはI、II、RUN、SELECTの4つ。
  - 回転: I／II
  - パドルを手で動かす（MDのC）: SELECTを押している間
  - ポーズ: RUN
  - ゲームオーバー画面はRUNで進む（MDのSTART）。
- RUN+SELECTのリセットは、ゲーム中は効かなくする（SELECTを押したままポーズしても落ちないように）。タイトル画面でだけ効く。
- 6ボタンパッドへの対応はしない。

## 6. ご褒美の絵（描き直し）
- 日本のアニメ調で20枚描き直す（ミカ10枚、ゴウ10枚）。アニメ調を最優先する（ユーザー指示）。大人に見えることと両立させる。
- ミカ: 成人女性。美人系、7〜8頭身で大人の体つき、化粧とアクセサリーあり、落ち着いた表情。
- ゴウ: 成人男性。がっしりしたイケメンのマッチョ。
- 服はステージごとに軽くなり、10面の大人っぽい水着で止める。
- 守ること（MD版12章と同じ）:
  - 裸、下着、性的なポーズはなし。
  - 子どもっぽい顔や体、制服、スクール水着、子どもを思わせる小物はなし。
  - 実在の人物や既存のキャラクターに似せない。
  - 水着は普通の襟ぐりと脚の切れ込みにする。
  - Grokの規約と法律を守る。
- 1枚ずつ企画が確認してからゲームに入れる。
- 画面に出すときは256x160、640タイル以内。パレットは背景用16本まで使ってよい（最大241色）。

## 7. 合格の条件
- 注意文 → タイトル → キャラ選び → ゲーム → エンディングまで、Mednafenで通して動く。
- 自動プレイで、1〜3面は必ずクリアでき、7面以降はときどき負ける（MD版14章と同じ）。
- 完成版にデバッグキーを残さない。
- ご褒美の絵20枚が、すべて企画の確認に通っている。

## 8. 難しさのテスト（2026-10-14 決定）
- 難しさの数字はMD版のまま。
- 自動プレイは、ボールが落ちそうなときにSELECTで手で受ける動きを入れる（人が遊ぶ前提に合わせる）。
- 合格: その自動プレイで24通り中、ステージ1〜3を全部クリア。7面以降はときどき負ける。
- 自動パドルだけのテストは参考値として記録する。

## 9. MD版との違い（2026-10-14 決定）
- ブロックの出方: 生きている敵の色で形が決まるのはMD版と同じ。ただし同じ色の敵だけが残ったときは、6個に1個の割合で点か2マスの棒を混ぜる（青だけ残ると角・四角が長く続き詰むため）。
- MD版はユーザー合格済みのため変更しない。

- Reward picture screen: MD changes the background color per picture; PCE keeps palette 0 and leaves the background black (approved 2026-10-14).
