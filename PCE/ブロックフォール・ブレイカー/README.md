# ブロックフォール・ブレイカー（PCエンジン）

> これはフリーで配布されたゲームです。製品版はありません。もし買われた方がいたらそれは詐欺です。警察に相談してください。
> GrokBOTでチームを組んで作成しました。

## ダウンロード
- [blockfall_breaker.pce](blockfall_breaker.pce)：PCエンジン（HuCARD）用のROMです（1MB）。

## 動かし方
- PCエンジン用のエミュレーターで開いてください。snes9xなど、ほかの機種用のエミュレーターでは動きません。
- 動作を確かめたのは **RetroArch ＋ Beetle PCE Fast コア** だけです。BIOSのファイルはいりません。
- Mednafen や Ootake でも動くはずですが、まだ試していません。

## 操作
- 十字キー：ピースを動かす
- I／II ボタン：回転
- RUN：一時停止
- SELECT を押している間：パドルを手で動かす
- タイトル画面で RUN ＋ SELECT：リセット

## どんなゲーム？
落ち物パズル、ブロック崩し、シューティングを合わせたパズルゲームです。上から下りてくる敵がピースを落としてきます。列をそろえて消すと、その数だけパドルからボールが飛び出して、敵を倒します。全10ステージで、5と10はボス戦です。エンドレスモードとギャラリーもあります。

ご褒美の絵は、日本のアニメ調で描いた成人のミカとマッチョなゴウが10枚ずつ、合わせて20枚です。
