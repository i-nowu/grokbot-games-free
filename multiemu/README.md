# 異能ソフト マルチエミュ (ブラウザ版)

**異能ソフト製** のブラウザで動くマルチエミュレーター。インストール不要、ROMやセーブはこの端末のブラウザの中だけに保存され、外部には送らない。

> 市販ソフトの動作は無保証。ROMやBIOSは自分で正規に入手したものだけを使ってね

## 対応機種

| 機種 | 内蔵ゲーム | 読み込めるファイル | BIOS |
|---|---|---|---|
| ゲームボーイ / ゲームボーイカラー | グンマー教の野望・ババ抜き・ブロックフォール・ブレイカー | .gb .gbc (.zip も可) | 不要 (SameBoy のオープンブートROM) |
| ネオジオ (MVS / AES) | シム群馬 | .neo、ネオジオのROMセット .zip (分割zip・7-Zip分割も可) | 異能ソフト自作 BIOS の無償配布版 (v0.6) を同梱 |
| Atari Lynx | なし | .lnx .o .lyx (.zip も可) | 不要 (HLE ブート) |

PCエンジン・ゲームギア・MSX などはメニューに「準備中」と出るだけで、まだ遊べない。
**C-BIOS (MSX 用) は同梱していない。** MSX コアもこの版には入っていない。
SNK BIOS・Universe BIOS・任天堂/Atari 純正BIOS・市販ROMも同梱していない。

## 同梱しているBIOS

同梱しているのは **異能ソフト自作 BIOS の無償配布版** (ネオジオ用 TEST BIOS v0.6) だけ。無償配布のみ可能。
**有償ソフトに添付されていたら詐欺なので、警察に通報してね。**
BIOS の中にも同じ内容の文 (英語と日本語) を入れてある。

## 使い方

1. このフォルダを Web サーバーで公開する (GitHub Pages など。ローカルなら `python3 -m http.server` で開いて `http://localhost:8000/` へ)。`file://` で直接開くと動かないことがある。
2. メニューで機種を選ぶと内蔵ゲームが始まる。画面をタップ / キーを押すと音が出る。
3. 自分のROMで遊ぶときは「ROMファイルを開く」かドラッグ&ドロップ。機種は自動判定。
4. 上のバー: メニュー / ゲーム切替 / RESET / ROM / ステート (セーブ・ロード) / 音 / パッド / ライセンス。スマホでは画面のパッドで操作。
5. ステートやセーブはブラウザ内 (IndexedDB) に保存。ステート画面からバックアップ (.mebak) の書き出し・読み込みができる。

キーボード (共通: 十字=矢印キー、スタート=Enter):
- GB/GBC: A=X、B=Z、セレクト=右Shift / Backspace
- ネオジオ: A=Z、B=X、C=A、D=S、コイン=5 / C、セレクト=右Shift
- Lynx: A=X、B=Z、オプション1=A、オプション2=S

## 内蔵ゲームとライセンス

- 内蔵ゲームの出所と md5 → `GENGAMES.md`
- 使っている第三者ソフトのライセンス → `THIRD_PARTY_LICENSES.txt` (アプリの「ライセンス」ボタンでも見られる)
- 全ファイルの md5 → `FILES_MD5.txt`

## 安全のための仕組み (2026-10-24 c 版)

- Content-Security-Policy を index.html に入れている。読み込めるのは同じ場所のファイルだけで、外部サーバーへの通信はできない。
- ZIP は展開しながら大きさを確かめ、目次の大きさか 64MB を超えたら止めて、理由を画面に出す (zip bomb 対策)。
- バックアップ (.mebak) の各項目の大きさが 0 以上の整数でなければ読み込まない。
- 別タブからの知らせ (BroadcastChannel) は、決まった形式のキーだけ受け付ける。

## d・e 版で変えたこと (2026-10-24)

- 試験用の機能を外した。
- IndexedDB が使えないブラウザでは「保存できません」と上に出す。
- 起動できなかったときは、その理由を画面に出す。
- Lynx の .o / .lyx は、ヘッダや大きさがおかしければ読み込まずに理由を出す。
- ピンチで拡大できるようにした (ボタンの上では効かない)。
- 読み込み枠の外にファイルを落としても、ページから離れない。
