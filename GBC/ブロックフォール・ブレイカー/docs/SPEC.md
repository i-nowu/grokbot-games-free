# ブロックフォール・ブレイカー ゲームボーイカラー版 移植仕様 v1（GB企画）

元: /workspace/pce-puzzle/docs/SPEC.md（PCE版）と /workspace/md-puzzle/docs/SPEC.md（MD版）。書いていないことはPCE版と同じ。

## 1. 方針
- ゲームの中身、ステージ10面（5・10面ボス）、クリアモード／エンドレス／ギャラリー、点数、難しさの数字（MD版14章と追記）はPCE版と同じ。
- PCE版9章のブロックの出方（同じ色の敵だけ残ったら6個に1個、点か棒2を混ぜる）も入れる。
- 起動時の注意文は一字一句同じ。1行に1文。文の途中で改行しない。
  これはフリーで配布されたゲームです。

  もし買われた方がいたらそれは詐欺です。
  警察に相談してください。
  GrokBOTでチームを組んで作成しました。
- テトリスの名前と絵は使わない。

- カラー専用（CGB-only、ヘッダ0x143=$C0）。白黒のゲームボーイでは、動かないことを伝える1画面だけ出す。

## 2. ハード（開発: GBDK-2020、テスト: SameBoy／BGB／Emulicious）
- 画面160x144。BGパレット8本、OBJパレット8本、各4色（OBJは1色透明）。
- スプライト40個、横1ラインに10個まで。
- VRAM 8KBx2バンク（タイル384個x2）。BGの属性マップでタイルごとにパレットとバンクを選べる。
- MBC5、ROM 1MB以内。セーブなし（ハイスコアは電源を切るまで）。倍速モードを使ってよい。
- 音: APU 4ch（矩形2、波形メモリ1、ノイズ1）。

## 3. 画面
- 1マスは8x8のまま（盤面80x192）。縦にスクロールして、見えるのは18行。6x6案はやめる（1タイルに色が3〜4色乗ってCGBのパレットで出せないため）。
  - スクロールは落下ピースと積んだブロックのいちばん上が見えるように追う。インベーダー帯が見えない間も、敵がいる列の位置を情報欄に小さく出す（要検証、企画が画面写真で確かめる）。
  - 盤面はBG。転送は変わったタイルだけを1回のVBlankで送る（全体2.3KBの描き直しはしない）。間に合わない分は次のVBlankに回す。
- ボール（最大4）、パドル、落下ピース、UFO、爆発はスプライト。敵はBG。
- 1ラインに10個を超えるときの優先順: ボール ＞ パドル ＞ 落下ピース ＞ UFO ＞ 爆発。はみ出す下位のものは1フレームおきに交代で出す（ちらつかせる）。
- 右側（80px）に情報欄。狭いので、スコア、ステージ、ネクスト、残り敵数を優先。ハイスコア、タイム、キャラ名はポーズ画面に回してよい。
- 色: ブロック7種を8本のBGパレットに割り振る（1本は文字と枠）。

## 4. 操作
- 回転: A（右）／B（左）。十字: 移動、下＝速く、上＝すぐ落とす。
- パドルを手で動かす: SELECTを押している間。
- ポーズ: START。ゲームオーバー画面はSTARTで進む。
- リセット（A+B+START+SELECT）はタイトル画面でだけ効く。

## 5. 音
- PCE版の6ch曲を4chに編曲し直す（矩形2＝メロディと和音、波形＝ベース、ノイズ＝リズム）。hUGETracker可。
- 効果音は鳴っている間だけ1chを借りる（矩形2かノイズ）。効果音が聞き取れるかをGB音楽が確かめる。

## 6. ご褒美の絵（要検証）
- 案: 160x112（20x14=280タイル）、タイルごとにBGパレット8本（各4色、最大32色）。1バンク（384タイル）に入る。1枚あたり約4.5KB＋マップと属性560バイト、20枚で約100〜120KB、ROMに入る。
- PCE版の20枚を縮めて色を減らし直す。守ること（成人、裸・下着・性的なポーズなし、最後は大人の普通の水着まで、子どもっぽくしない、実在・既存キャラに似せない、アニメ調最優先）はPCE版と同じ。
- まず2枚（ミカ1面、ゴウ10面）で試作し、企画が見て判断する。顔がつぶれる、子どもっぽく見えるなら、ご褒美の絵は入れずに「ステージクリア画面」だけにする（ギャラリーもなし）。
- 入れるときは20枚を1枚ずつ企画が確認する。

## 7. 合格の条件
- 注意文が上の5行のとおり（画面写真で一字ずつ照合）。
- 注意文 → タイトル → キャラ選び → ゲーム → エンディング → 注意文 → タイトルまで通して動く。
- 完成版にデバッグキーが残っていない。
- 難しさのテスト（PCE版8章と同じ）: SELECT相当の手動受けを入れた自動プレイで24通り中、ステージ1〜3は全部クリア。7面以降でときどき負ける。自動パドルだけの結果は参考値として記録。
- 1ライン10個を超えるとき、3章の優先順のとおりに出る（ボールとパドルは消えない）。
- 白黒機の扱い（1画面の案内）が動く。

- 2026-10-15 決定: GBCにもご褒美の絵20枚（160x112）とギャラリーを入れる。肌の色を優先してパレットを割り当てる。空や窓のブロック状の荒れは許容する。

- 2026-10-15 合格条件の変更（8章を上書き）: (1) 共通のゲームの中身（bfb-core）がPCE版と突き合わせてずれ0。(2) 自動パドルのボットが24通りすべてで1〜3面をクリア。手動パドルのボットは参考扱いで、負けた面を毎回報告する。理由: 処理の遅れがない機種ではボットの入力タイミングが変わり、同じseedでも展開が変わるため。

- 2026-10-15 GB企画決定: 条件2を「タイトルでの実際のシード値で固定した24個(全機種共通)について、PCEと同じ入力を与えて全24回の結果(クリア面・負けた面・スコア)がPCEと一致すること」に変更。クリア数そのものは問わない。

- 2026-10-15 決定: 任天堂ロゴ欄は空(参謀決定)、エミュレーター専用。注意文の「GrokBOT」は半角4x8。画面外の敵の列は最上段に▲表示。タイトルはローマ字表記。
