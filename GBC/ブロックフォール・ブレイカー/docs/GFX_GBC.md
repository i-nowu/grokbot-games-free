# GBC 絵の形式
- ブロック 8x8（縦スクロール）: 1マス=1タイル。`res/block8x8.2bpp`（全種共通16B）＋ `res/block8x8.pal`（BGパレット8本x4色 BGR555、0〜6=ブロック7種〔背景/明/中/暗〕、7=文字・枠）。色は属性マップのパレット番号で変える。モック `res/preview/board_8x8_scroll_mock.png`。
- ご褒美の絵（20枚, 採用）: 肌優先（肌色画素の重み6倍、肌タイルをまとめて肌用パレットを確保）。 承認済み256x160の内側 x=14〜241 を160x112に縮小、20x14=280タイル（重複まとめなし）、タイルごとにBGパレット8本x4色から選ぶ。
  - `res/pics/NAME.2bpp`（4,480B）、`NAME.attr`（280B、パレット番号）、`NAME.pal`（64B）。変換 `tools/gfx/conv_gbc.py`。
  - 確認: `res/preview/NAME_gbc_x3.png`（元を縮めたもの `_gbc_ref_x3`）、並べた比較 `gbc_trial_compare.png`、一覧 `gbc_all_x2.png`。
- 盤面スプライト 8x8（`tools/gfx/gen_sprites8.py`、GBA版の絵を8x8に描き直し）:
  - `res/sprites8.2bpp` 16タイル256B。0壁 1-2カニ 3-4おばけ 5-6目玉 7-8コウモリ（種類x2+コマ）9-12ボス16x16（左上,右上,左下,右下）13爆発 14ひび 15星。一覧 `res/sprites8.txt`。
  - `res/sprites8.attr` 16B＝各タイルのBGパレット番号。BGパレットは0〜7がすべて使用中なので、新しいパレットは作らずブロック用を共用: 壁・ひび=6灰、カニ=1青、おばけ=4紫、目玉=3緑、コウモリ・星=2黄、ボス=0赤、爆発=5橙。色0は背景色のまま。
  - 組込み: タイルをVRAMに置き、盤面の属性マップにそのセルのパレット番号を書く（ブロックと同じ仕組み）。OBJパレットは使わない（パドル・ボール用に空けておく）。
  - 確認: `res/preview/sprites8_x4.png`、`res/preview/board_8x8_sprites_mock_x4.png`。
- キャラ選びの顔 48x56（6x7=42タイル/人）:
  - `res/face_mika.2bpp` / `face_gou.2bpp`（各672B、行優先）、`.attr`（各42B）。ミカ=BGパレット0〜2、ゴウ=3〜5。
  - `res/face_charsel.pal` 64B＝キャラ選び画面用のBGパレット8本（0〜5顔、6灰ブロック、7文字＝現行のまま）。この画面に入るときに読み込み、出るときに `block8x8.pal` に戻す。
  - 肌優先（conv_gbc.pyと同じ、肌の重み6倍）。元: PCE承認crop256の mika02 x90〜149,y6〜75、gou03 x82〜141,y0〜69（承認範囲内、ミカ10は不使用）を0.8倍。
  - 確認: `res/preview/charsel_faces_x4.png`（左の顔はタイル(2,3)、右は(12,3)に置いた例）。
- OBJ ボール・UFO・パドル（`tools/gfx/gen_obj8.py`）:
  - `res/obj8.2bpp` 5タイル80B = obj_tiles 0〜4 をそのまま差し替え（0ボール 7x7の丸、1UFO、2〜4パドル24x8の左・中・右）。大きさ・コマ数・置き方は main.c の今の呼び方のまま（ボール x-4,y-4、パドル x-12 から3枚）。
  - OBJパレット0（透明・白・灰・紺）を使う。今の割当てどおりで変更なし。OBJパレットは0＝ボール・パドル・UFO・カーソル・文字、1〜7＝ブロック（落ちるピース）、6＝爆発（橙）で8本とも使用中。新しいパレットは足していない。
  - 組込み: `tools/gen_res_gbc.py` で、tiles.png から作っている ot の最初の5タイル（ボール、UFO、パドル）を `obj8.2bpp` に置き換える。
- ▲ 敵インジケーター（BG）: `res/ind8.2bpp` 1タイル16B。BGパレット7（0＝盤面背景と同じ色、1白、2灰）。空いているBGタイル 213〜231 のどれか（例 213）に置き、盤面の一番上の行で、敵が画面の上に隠れている列に属性7で出す。
  - 確認: `res/preview/obj8_x4.png`、モック `res/preview/obj8_mock_x4.png`。
