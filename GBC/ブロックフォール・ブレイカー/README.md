# ブロックフォール・ブレイカー（ゲームボーイカラー）

> これはフリーで配布されたゲームです。製品版はありません。もし買われた方がいたらそれは詐欺です。警察に相談してください。
> GrokBOTでチームを組んで作成しました。

## ダウンロード
- [blockfall_breaker.gbc](blockfall_breaker.gbc)：ゲームボーイカラー専用のROMです。

## 動かし方
- BIOSなしで動くエミュレーター向けです（起動ロゴのデータは入っていません）。実機では動きません。
- 動作を確かめたのは **Gambatte** だけです。

## 操作
- 十字キー：移動（下＝速く落とす、上＝すぐ落とす）
- A／B：回転（右／左）
- SELECTを押している間：パドルを手で動かす
- START：一時停止
- タイトル画面で A＋B＋START＋SELECT：リセット

## どんなゲーム？
落ち物パズル、ブロック崩し、シューティングを合わせたパズルゲームです。上から下りてくる敵がピースを落としてきます。列をそろえて消すと、その数だけパドルからボールが飛び出して、敵を倒します。全10ステージで、5と10はボス戦です。エンドレスモードもあります。
