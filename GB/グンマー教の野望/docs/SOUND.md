# サウンドの作り方 (GB音楽)

## 方式
hUGEDriverは使わず、GBDK-2020のCで書いた小さな自作ドライバ（`src/sound.c`）を2本で共通に使っています。
- 曲：ch2がメロディ（矩形波）、ch3がベース（波形メモリ）。
- 効果音：ch1（ババ抜きはJOKERでch4も使用）。グンマー教の野望は、発射と撃破をch4（ノイズ）、それ以外をch1に分け、連射しても他の効果音が消えないようにしています。
- 更新：起動時に `snd_init()`、`add_VBL(snd_update)` で毎フレーム自動更新。

## 曲データの作り方
`tools/snd/gen.py` に「音名:長さ」で楽譜を書き（例 `E5:2 G5:2 C6:4`、長さ1＝16分音符＝6フレーム、`R`は休符）、実行すると `src/sound_data.c` を生成します。
```
python3 tools/snd/gen.py && make
```

## 収録内容
| ゲーム | 曲 | 効果音 |
|---|---|---|
| ババ抜き | タイトル（ループ）、勝ち・負けジングル | カーソル、引く、ペア、上がり、ジョーカー |
| グンマー教の野望（6面） | タイトル、戦闘（全面共通）、ボス戦（各面10ウェーブ目）、クリア（エンディングでも使用）・ゲームオーバー | カーソル、設置、強化、売却、発射、撃破、ライフ減少 |

## デバッグ
- 音だけのテストROM（曲を流し、Aで効果音）をビルドして確認。
- 効果音は割り込み中に更新するため、鳴らす瞬間に割り込みが重なっても音が途切れないよう順序を調整済み。
- 制作環境では実際の音を聴けないため、音量バランスはmGBAで遊んで耳で確認・調整するのが残り作業です。

## 試聴
`python3 tools/snd/preview.py` で、曲を近い音色で再現したWAVを `build/preview/` に書き出せます（グンマー教の野望）。
