# グンマー教の野望 仕様書 v1（GB企画）

## 1. 概要
- ジャンル: タワーディフェンス（固定ルートを進む敵を、ユニット配置で防ぐ）。
- 対象: DMG。ROM 32KB目標、超えたら MBC1。
- 設定（ネタ・架空）: 秘境「グンマー」の謎の教団が、平和な町へ向けて信者たちを送り込んでくる。プレイヤーは町の守備隊長。
  ※実在の団体・人物は出さない。地名ネタは軽い冗談の範囲。
- 起動時の注意書き画面: ババ抜きと同じ文面・同じ仕様（Aか STARTでタイトルへ）。

## 2. 画面構成（160x144 = 20x18タイル）
- 上1行: ステータス（おかね / ライフ / ウェーブ n/10）。
- 中央 20x15: マップ。8x8タイル単位、ユニットは1マス（8x8）または2x2。
- 下2行: メッセージ・選択中ユニット名とコスト。
- 敵の通り道は固定の1本道（左端の入口→右端の町）。道以外の空きマスにユニットを置ける。

## 3. 画面の流れ
注意書き → タイトル → ステージ選択(3面) → 準備フェーズ → ウェーブ戦闘 ⇄ 準備 → クリア/ゲームオーバー → タイトル

## 4. ルール
- ライフ 10。敵が町（右端）に着くたび -1、0で負け。
- 全10ウェーブ守り切ればステージクリア。3ステージ。
- 敵を倒すとおかね獲得。ウェーブ間に配置・強化・売却ができる。戦闘中も配置可。
- 売却は払った額の半分が戻る。

## 5. ユニット（守備側）
| 名前 | コスト | 攻撃 | 射程 | 特徴 |
|---|---|---|---|---|
| こめや | 10 | 弱 | 短 | 安い基本ユニット |
| やきまんじゅう屋 | 20 | 中 | 中 | 標準 |
| からっかぜ扇風機 | 25 | 0 | 中 | 範囲内の敵を遅くする |
| こんにゃく砲 | 40 | 強 | 長 | 発射が遅い |
- 強化: 各ユニット2段階まで（コスト同額で攻撃+50%）。

## 6. 敵（グンマー教）
| 名前 | 体力 | 速さ | 報酬 | 出現 |
|---|---|---|---|---|
| しんじゃ | 低 | 普通 | 2 | 1〜 |
| はしりや | 低 | 速い | 3 | 3〜 |
| おおがら | 高 | 遅い | 5 | 5〜 |
| きょうそ（ボス）| 特大 | 遅い | 30 | 各ステージ10ウェーブ目 |
- 画面上の敵は最大 8体（スプライト制限: 1体2x2=4スプライト、1ライン10個を守る）。

## 7. 操作
| ボタン | 準備/戦闘中 |
|---|---|
| 十字 | カーソル移動（マス単位） |
| A | 空きマス: ユニット選択→設置 / ユニット上: 強化 |
| B | キャンセル、ユニット上で長押し: 売却 |
| SELECT | ユニットの種類を切り替え |
| START | 準備中: ウェーブ開始 / 戦闘中: ポーズ |

## 8. サウンド
- BGM: タイトル、戦闘（ループ）、ボス戦。
- ジングル: クリア、ゲームオーバー。
- SE: カーソル、設置、強化、売却、発射、撃破、ライフ減少。

## 9. グラフィック
- マップタイル: 草地、道、木、川、町。ステージごとに道の形だけ変更。
- ユニット4種×強化3段階の見た目（色違いで可）、敵4種（2フレーム歩き）、弾、カーソル。
- フォント: 8x8ドットのフォント（使う字だけタイル化）。

## 10. 完成条件
- 3ステージを通しで遊べ、クリアとゲームオーバーが正しく出る。
- 敵最大数でも処理落ちせず、スプライトがちらつかない（またはちらつきが目立たない）。

## 11. 難易度の目安（v1.1 追加・テスト時の合格ライン）
- 初期おかね: 50（こめや＋やきまんじゅう屋を2〜3個置ける程度）。
- ステージ1: 何も考えずに置いても、ライフが5以上残ってクリアできる。
- ステージ2: 扇風機を使わないとライフが3〜6残る程度。
- ステージ3: ボスはこんにゃく砲を強化して当てないと抜けられる。上手く置けばライフ8以上残せる。
- 1ウェーブの長さ: 30〜60秒。ボスのウェーブは90秒以内。
- どのステージでも「ユニットを1つも置かない」と必ず負ける。「最適な置き方」なら必ずクリアできる（詰まないこと）。
- 自動テストでは、決めた置き方を最低3パターン（何も置かない／適当／強い置き方）で回し、上のライン通りかを確認する。

## 12. 6面化とエンディング（v1.2 追加・ユーザー指示）
- 目的: グンマー帝国から「一都5県」を救う。全6面、最後の東京を救えばクリア。
- 面の順番（群馬から近い順）:
  1. 栃木 2. 茨城 3. 埼玉 4. 千葉 5. 神奈川 6. 東京
- 各面の最初に「○○を すくえ！」、クリアで「○○を すくった！」を表示。
- 既存3面のマップは1〜3面に流用。4〜6面は新しい道の形（千葉=海沿い、神奈川=山道、東京=ビル街で曲がり角が多い）。
- 難易度: 11章の目安をそのまま延長。面ごとに少しずつ敵を固くし、6面のボス「きょうそ」がいちばん強い。最初のおかねは70→50へ段階的に下げる（40では強い置き方でも神奈川を抜けられないため、50に変更）。
- エンディング（6面クリア後）:
```
あなたは グンマーていこくから
かんとうを かいほうしました！
えらい！
```
  ジングルはクリアのものを流用。AかSTARTでタイトルへ戻る（または数秒後に自動で戻る）。
- 使う文字が増えるので、地名の漢字（栃木 茨城 埼玉 千葉 神奈川 東京）はフォントから追加する。
