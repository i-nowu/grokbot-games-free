# プログラムとデバッグ（GBプログラマー）

## 使っているもの
- 言語: C（GBDK-2020）。ROMは32KB、MBCなし。
- ビルド: 各プロジェクトのフォルダで `make` → `build/*.gb`。`make run` でmGBAを起動。

## コードの構成
| ファイル | 中身 | 担当 |
|---|---|---|
| `src/main.c` | 画面の流れ、ゲームのルール、入力、描画 | プログラマー |
| `src/gfx*.c/h` | タイル・定型文（スクリプトで生成、手で編集しない） | グラフィック |
| `src/sound*.c/h` | 自作サウンドドライバと曲データ | 音楽 |

- ババ抜き: 注意書き → タイトル → 配る → ペアを捨てる → 手番のループ → 結果。カードは1バイト（上位4bitがスート、下位4bitが数字、ジョーカー=0xFF）。
- グンマー教の野望: 注意書き → タイトル → ステージ選択（栃木・茨城・埼玉・千葉・神奈川・東京の6面） → 準備と戦闘のループ → 「○○を すくった!」/ゲームオーバー → 東京を救うとエンディング → タイトル。道は折れ点のリストからマスの並びを作り、敵はその上を「進んだ距離」で動かします。スプライトは8x16モードで、1ラインの上限(10個)を超えるときは毎フレーム表示順を入れ替えます。
- 音は `add_VBL(snd_update)` で毎フレーム更新します。

## デバッグの方法
1. **ルールのテスト（PC上）**: ゲームの判定部分を同じ手順でPC用のCに写し、大量に対戦させます。
   - ババ抜き: `gcc test/sim.c -o sim && ./sim`。10万回対戦させて、おかしな終わり方0回、手札の最大14枚を確認済み。
   - グンマー教の野望: `python3 test/sim.py 50`。6面それぞれ「何も置かない／適当に置く／強く置く」で50回ずつ回し、何も置かなければ必ず負け、強く置けば必ずクリアを確認済み。
2. **画面のテスト（エミュレータ）**: PyBoyでROMを画面なしで動かし、ボタンを自動で押して画面を撮ります。
   - グンマー教の野望: `python3 test/run.py` → `test/s*.png`。
3. **手で遊ぶ確認**: `make run` でmGBAを起動して通しプレイ。音量はここでしか確かめられません。

   - グンマー教の野望の通しテスト: `python3 test/rom_playthrough.py`（`NOPLACE=1` で何も置かない場合）。6面すべてとエンディングまで確認済み。
