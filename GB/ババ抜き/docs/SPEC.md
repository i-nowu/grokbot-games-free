# ババ抜き GB 仕様書 v1（GB企画）

## 1. 概要
- 対象: DMG（白黒4階調）、ROM 32KB想定（MBCなし）。
- 人数: プレイヤー1人（P）＋CPU3人（C1〜C3）。
- カード: 52枚＋ジョーカー1枚＝53枚。
- 目標: 最後にジョーカーを持っていた人が負け。プレイヤーの勝敗は「ジョーカーを持たずに上がれたか」で判定。

## 2. ルール
1. 53枚をシャッフルし、P→C1→C2→C3の順に1枚ずつ配る（P/C1/C2が14枚、C3が13枚）。
2. 配った直後、全員が同じ数字のペアを自動で捨てる（スートは問わない。3枚あれば2枚捨て1枚残る）。
3. 手番順: P → C1 → C2 → C3 → P …（時計回り）。
4. 手番の人は「次の人のうち、まだ手札が残っている人」の手札から1枚引く。
   - Pは C1 から引く（C1が上がっていれば C2、さらに C3）。
5. 引いたカードと同じ数字があればペアで捨てる。
6. 手札が0枚になった人は上がり（順位を記録）。引かれて0枚になった人も上がり。
7. 残り1人になったら終了。その人（ジョーカー所持）が負け。
8. 上がった人の手番はスキップする。

## 3. CPUの思考
- 引く位置: 相手手札からランダムに1枚（乱数）。
- 引かれる側のCPUは手札をシャッフルしてから並べる（毎手番後に軽くシャッフル）。
- CPUの演出: カーソルが手札上を0.5秒程度動いてから決定（体感用。任意）。

## 4. 画面の流れ
```
タイトル → (START) → 配る演出 → ペア捨て表示 → ゲーム本編 ⇄ (ペア成立表示) → 結果画面 → (START) → タイトル
```

### 4.1 タイトル
- ロゴ「ババぬき」、「PUSH START」点滅。タイトル曲ループ。
- START で開始。乱数シードはタイトル待機中のフレーム数＋DIVレジスタで決める。

### 4.2 ゲーム本編（160x144）
- 上段: C2の手札（裏向き、枚数表示）。
- 左/右: C1・C3の手札枚数（裏向きカード1枚＋「×N」）。
- 中央: メッセージ欄（「C1のばん」「ペア！」など1行）。
- 下段: Pの手札（表向き）。13枚以上は横スクロール、または重ねて表示。
- 引く対象の手札は画面下中央に裏向きで横並び（最大14枚。入りきらない場合は左右スクロール）。
- 上がった人の位置には「あがり」と順位表示。

### 4.3 結果画面
- 「あなたの かち！」（ジョーカーなしで上がった）／「あなたの まけ…」（最後にジョーカー所持）。
- 全員の順位一覧（1〜4位）。勝ち/負けジングル。
- START でタイトルへ。

## 5. 操作
| ボタン | タイトル | 自分の手番（引く） | 結果 |
|---|---|---|---|
| 十字 左右 | – | 引くカードを選ぶ | – |
| A | 開始 | そのカードを引く | タイトルへ |
| B | – | 自分の手札を見る/戻す（任意） | – |
| START | 開始 | ポーズ（任意） | タイトルへ |
| SELECT | – | 自分の手札をシャッフル（見た目のみ・任意） | – |
- CPU手番やメッセージ表示中は A で早送り可。

## 6. 演出・サウンド（音楽担当向け）
- タイトルBGM（ループ）、勝ちジングル、負けジングル。
- SE: カーソル移動、決定（引く）、ペア成立、上がり、ジョーカーを引いた時。

## 7. グラフィック（グラフィック担当向け）
- カード表: 数字A〜K＋スート4種、ジョーカー。1枚 16x24px（2x3タイル）推奨。
  - タイル節約案: 数字タイル13＋スートタイル4＋枠タイルの組み合わせで描画。
- カード裏: 1種。
- カーソル: スプライト（8x8 矢印）。
- フォント: 英数字＋必要なカナ（メッセージ用）。

## 8. 内部データ（プログラマー向け目安）
- カード表現: 1バイト。上位2bit=スート、下位4bit=数字1〜13、ジョーカー=0xFF など。
- 手札: 各プレイヤー最大 14枚＋1 の配列＋枚数。
- 状態: TITLE / DEAL / DISCARD / TURN_PLAYER / TURN_CPU / RESULT。

## 9. 完成の条件
- エミュレータでタイトル→本編→結果→タイトルまで止まらず遊べる。
- どの順番で上がっても正しく終了し、勝敗が正しく出る。
