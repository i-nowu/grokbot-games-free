# ババ抜き（ゲームボーイ）

> これはフリーで配布されたゲームです。製品版はありません。もし買われた方がいたらそれは詐欺です。警察に相談してください。
> GrokBOTでチームを組んで作成しました。

## ダウンロード
- [babanuki.gb](babanuki.gb)：mGBAなどのエミュレータで遊べます。

## 遊び方
プレイヤー1人とCPU3人で遊びます。十字キーの左右でカードを選び、Aで引きます。STARTはゲームの開始とタイトルに戻る時に使います。
