# グンマー教の野望 WS版 仕様書（GB企画）

## 1. 方針
- GB版のルール・数値・敵の出方をそのまま移す。変えない。
- 対象: ワンダースワン（白黒）。横持ち。Wonderful toolchain(C)。

## 2. 画面（224x144 = 28x18）
- GBの20x18をそのまま中央（4〜23列）に置く。左右4列ずつは草と木の飾りで、ゲームには関係しない。
- カーソルは中央20列の中だけ動く。

## 3. 操作
| ボタン | 役割（GB版の対応） |
|---|---|
| X1〜X4 | カーソル移動（十字） |
| A | A |
| B | B（長押しで売却） |
| Y1〜Y4どれでも | ユニット切り替え（SELECT） |
| START | START |

## 4. 合格条件
1. 共通の24シードに同じ入力を入れ、各ウェーブ終了時のおかね・ライフ・倒した数と最終結果がGB版と一致する。WSは約75.47fpsなので、ゲームの進み方はGB版と同じ秒数になるよう合わせる。
2. 注意書きが一言一句同じ。
3. 音がGB版と同じ曲・効果音で、途切れや欠けがない。
4. 20分遊んで止まらない・再起動しない。

- 2026-10-15 再合格: 9ca06da1… の中の絵（GBグラフィック）と音（GB音楽）を確認し、最終合格を維持。
