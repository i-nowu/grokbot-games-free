# ぐんま WS（モノクロ）グラフィック（GBグラフィック）
- ご褒美の絵：GB版ぐんまでは使っていないので、WS版にも入れない。

## タイルの範囲（2bpp の 512 枚の場所。0 番から続けて読み込む）
- `T_GRASS`=135 から：地形、町、ユニット（`T_UNIT(t,l)`）、HUD（`T_COIN`=169 など）。番号はすべて GB 版と同じ
- ロゴ：BG の最後まで（BG は 253 枚）
- スプライト：`GFX_SPR_BASE`=253 から 40 枚。敵（16x16）は 8x8 のスプライト 4 枚で描く。タイルの順番は GB と同じ TL、BL、TR、BR で、`SPR_ENEMY(e,f)` の +0 は (x,y)、+1 は (x,y+8)、+2 は (x+8,y)、+3 は (x+8,y+8)。弾は `SPR_BULLET`、こんにゃくは `SPR_KONNYAKU_SHOT`（風は `SPR_WIND`）、カーソルは `SPR_CURSOR_0` から 4 枚
- 敵 N 体ならスプライトは 4N 枚（128 枚まで＝32 体）。1 ラインに 32 枚までなので、横に並ぶ敵は 16 体まで（1 体の幅は 2 枚）

## パレット（0=白〜7=黒は、濃さの表の番号）
| 番号 | 色 0〜3 | 使い道 |
|---|---|---|
| 0 | 0,2,5,7 | BG（地図、文字、HUD）。GB の BGP=0xE4 と同じ並び |
| 1 | 7,5,2,0 | BG を白黒反転したもの（「ここにはおけない」の点滅、カーソル。使わなくてもよい） |
| 12 | 0,2,5,7 | スプライト。パレット 12 以上は色 0 が透明になる |

マップのエントリ：`GFX_MAP(tile,pal)` = タイル番号（ビット 0〜8）、パレット（ビット 9〜12）。ビット 14/15 は左右・上下の反転

## 画面の配置
- 仕様書（`docs/SPEC.md`）がまだなかったので、GB の 20x18 の画面を真ん中に置いた（`GFX_FIELD_X`=4、4〜23 列）。左右 4 列ずつは草と木で埋めた飾り。1 行目が HUD、17〜18 行目がメッセージ欄で、GB と同じ。

## 読み込み方
- タイル：`gfx_tiles` を 2bpp タイルの場所（0x2000）に `GFX_TILE_COUNT*16` バイトコピーする。
- 濃さの表：`gfx_shade_lut[0..3]` をポート 0x1C〜0x1F に `outportb` で書く。
- パレット：`gfx_pal` の 32 バイトを、ポート 0x20〜0x3F に書く。
- **`__far` 配列の注意**：手書きのループで IRAM にコピーすると DS がずれて画面が真っ白になる。`memcpy` かライブラリの関数を使うこと。
- 注意文：GB 版と同じく、注意文のタイルを先に読み、表示が終わったら本編のタイルを読み直す（注意文の絵はこのファイルには入っていない）。
