# グンマー教の野望（ワンダースワン）

> これはフリーで配布されたゲームです。製品版はありません。もし買われた方がいたらそれは詐欺です。警察に相談してください。
> GrokBOTでチームを組んで作成しました。

## ダウンロード
- [gunma_ws.ws](gunma_ws.ws)：ワンダースワン（白黒）用のROMです（128KB）。

## 動かし方
- ワンダースワン用のエミュレーターで、横持ちで遊びます。動作を確かめたのは **mednafen（wswan）** です。

## 操作
- X1〜X4：カーソル移動
- A：決定
- B：戻る（長押しで売却）
- Y1〜Y4のどれか：ユニット切り替え
- START：スタート／ポーズ

## どんなゲーム？
GB版「グンマー教の野望」のワンダースワン移植です。ルール、数値、敵の出方はGB版と同じです。
