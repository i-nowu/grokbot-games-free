# ババ抜き NGP グラフィック（GBグラフィック）

ご褒美の絵: GB版ババ抜きには **ない**。なので NGP 版にも入れない（新しい絵も足さない）。

## タイル番号
| 範囲 | 中身 |
|---|---|
| 117–119 | `T_CARD_TR / T_CARD_BL / T_CARD_BR` |
| 120–132 | `T_RANK_0..12`（A..K、カード左上） |
| 133–140 | `T_SUIT_S_L, T_SUIT_S_R, H, D, C`（s*2 で L、+1 で R） |
| 141–146 | `T_JOKER_0..5`（2x3、左上から右下） |
| 147–152 | `T_BACK_0..5`（2x3） |
| 153–155 | `T_SOLID_W/L/B` |
| 156–163 | `T_WIN_TL,T,TR,L,R,BL,B,BR`（メッセージ欄の枠） |
| 164–223 | タイトルロゴ（`logo_map_ngp.bin` から使う） |
| 224–226 | スプライト `T_SPR_ARROW_DOWN/UP/RIGHT` |

NGP はスプライトと BG で同じ512枚のキャラRAMを使うので、スプライトは BG の後ろに置いた。全部で227枚（512以内）。番号は全部 256 未満だが、マップは9bitなので上位ビットは0で書く。

## カード（2x3 タイル）
表: `RANK(r) , CARD_TR / SUIT_L(s), SUIT_R(s) / CARD_BL, CARD_BR`。手札を重ねるときは左の列だけ並べ、最後の1枚だけ2列にする（見本どおり）。

## パレット（白黒8階調）
- パレット0（通常）：1=明暗2（うすい灰）、2=5（こい灰）、3=7（黒）。GB の 4階調 0xE4 と同じ見え方。
- パレット1（反転）：選んだカードの点滅・強調に使う。
- 背景色（0x8118）：明暗0＝白。有効ビットを立てて `0x80` を書く。
- 読み込み：`pal_ngp.bin` の8Bを、スプライト 0x8100、SCR1 0x8108、SCR2 0x8110 にそれぞれ書く（0x8100+p*4+i）。SCR1 に盤面と文字、SCR2 は未使用（演出用に空けてある）。

## 画面の配置（20x19、見本 play_mock）
- 行0–5：C2（上、裏を重ねる）、C1（左上）、C3（右上）と枚数 `×n`
- 行8–11：メッセージ欄（枠＋**2行**。GB版より8px高い分）
- 行12：カーソル（スプライト ↓）、行13–15：自分の手札、行17：「あなた」と枚数

## 読み込み手順
1. キャラRAM 0xA000 に `tiles_ngp.bin` を 3632B コピー
2. パレットを書く（上記）
