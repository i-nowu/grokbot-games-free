# サウンド（ババ抜き NGP）— GB音楽

900H 側は共有RAMに指令を書くだけで、音源の操作はすべて Z80 が行う。

## 組み込み方（GBプログラマー向け）
1. 起動時に1回 `call snd_init`。毎フレーム（VBlank のあと）1回 `call snd_update`。
   ラグで1フレーム飛んだら、その分 `snd_update` を余分に呼べば GB版と同じく追いつく（GB版も「呼ばれた回数」で進む）。

## API（意味は GB版と同じ。番号も同じ）
| ルーチン | 入力 | 出力 | GB版 |
|---|---|---|---|
| `snd_init` | なし | なし | `snd_init()` |
| `snd_update` | なし | なし | `snd_update()` |
| `bgm_play` | A=曲番号（0 タイトル（ループ）、1 勝ち、2 負け。3以上・0FFh は停止） | なし | `music_play()` |
| `bgm_stop` | なし | なし | `music_stop()` |
| `sfx_play` | A=効果音番号（0 カーソル、1 決定、2 ペア、3 上がり、4 ジョーカー。5以上は無視） | なし | `se_play()` |
| `bgm_playing` | なし | A=1/0、Z=0 なら再生中 | `music_playing()` |
| `sfx_playing` | なし | A=1/0、Z=0 なら鳴動中 | （GB版には無い。音が消えるまで1） |

- レジスタ：A 以外は保存（`bgm_playing`/`sfx_playing` は A を返す）。**フラグは壊れる**。
- `bgm_play` 直後の `bgm_playing` は、Z80 がまだ受け取っていなくても 1 を返す（GB版と同じ）。
- 勝ち・負けは1回鳴って終わると `bgm_playing`=0 になる。

## 使うメモリ
- **共有RAM 7000h-7FFFh（4KB）は全部サウンドが使う。ゲーム側は読み書きしないこと。**
  - 7000h- Z80 プログラムとデータ（約1.7KB）
  - 7E00h-7E19h Z80 の変数、7FF0h より下は Z80 のスタック
  - 7F00h-7F08h 指令エリア：+0 フレーム数（snd_update が+1）、+1 曲指令、+2 曲指令の回数、+3 効果音指令、+4 効果音指令の回数、+5/+6 Z80 が受け取った回数、+7 曲再生中、+8 効果音鳴動中
- I/O：`snd_init` が 0B8h=55h（音源 ON）、0B9h=0AAh→55h（Z80 リセット→起動）を書く。0BAh（Z80 NMI）、0BCh、Z80 割り込みは使わない（Z80 は 7F00h を見て動く）。
- ROM：900H 側ルーチン約 0.1KB ＋ Z80 本体 1.7KB。

## チャンネルの割り当て
| GB | NGP (T6W28) |
|---|---|
| ch2 メロディ（矩形波 50%、エンベロープ A4h） | 矩形波 ch0。エンベロープは GB の 64Hz 減衰をフレームごとの表にした |
| ch3 ベース（波形メモリの三角波） | **周期ノイズ**（15段）。T6W28 の矩形波は 93.8Hz より低く出せず、GB のベースは譜面の1オクターブ下（49〜131Hz）で鳴っているため。ジョーカーのノイズが鳴っている間だけ、矩形波 ch1 で1オクターブ上に逃がす |
| ch1 効果音（スイープ付き矩形波） | 矩形波 ch2。GB のスイープ・エンベロープをフレームごとに計算した表 |
| ch4 ジョーカーのノイズ | ノイズ（白色、1627Hz。GB は 1638Hz） |

左右とも同じ音量（GB版も NR51=FFh で中央）。

## テンポ
GB版はフレーム数で進む（59.73Hz）。NGP は 59.95Hz なので、Z80 が 16bit の積算（`KACC`=65293/65536）で 1000 フレームに約 4 回だけ進みを休み、GB版と同じ秒数にしている。

## 測定（mednafen_ngp で録音、聴かずに数値だけ）
| 録音 | ピーク | クリップ | 50ms 無音窓 |
|---|---|---|---|
| title25s.wav（タイトル 25秒） | 5394（-15.7dBFS） | 0 | 0 |
| win.wav / lose.wav | 5355 / 5382 | 0 | 0 |
| se_all.wav（効果音 0〜4 を順に） | 5650 | 0 | 71（効果音どうしの間のすき間。意図どおり） |
| mix.wav（タイトル＋ジョーカー＋ペア） | 7757（-12.5dBFS） | 0 | 0 |

- テンポ（メロディの打点の自己相関）：NGP 拍 0.2012s・1周 6.855s、GB 録音 拍 0.2034s・1周 6.866s（理論 0.2009s・6.831s）。差 -0.2%。
- 勝ちのメロディ長：1.310s（GB 理論 1.306s）。
- 音程：E5 657.4Hz（-0.28%）、G5 787.1Hz（+0.40%）、C6 1043.4Hz（-0.30%）、ベース C（GB実音 65.41Hz）65.36Hz、ベース G（98.0Hz）98.39Hz、カーソル音 525.0Hz（GB 524.3Hz）。誤差は T6W28 の周期の刻み（最大 0.5% 前後）。
- 停止後は無音（0.1s 以降ピーク 1）。

## GB版との違い
- 矩形波のデューティは 50% だけ。ジョーカーの矩形波（GB は 12.5%）は音色が少し太くなる。
- ベースは三角波ではなく周期ノイズのパルス音なので、高さは同じだが音色は硬い。
- 音量は GB の直線の音量を T6W28 の 2dB 刻みの減衰に丸めた。
- ベースの周期ノイズは mednafen の T6W28 実装（15段）で確かめた。実機の T6W28 の周期ノイズの段数は未確認。
