# ババ抜き NGP 仕様書 v1（GB企画, 2026-10-15）

## 1. 元
- GB版のルール・CPU思考・画面の流れをそのまま移す。ルールの変更なし。

## 2. 機種
- NeoGeo Pocket（白黒8階調）。aslでアセンブリ。mednafen_ngp（BIOSなし）で確認。エミュレーター専用。
- メインループで毎回 `(6Fh)=4Eh` を書く。

## 3. 操作
- スティック左右: 引くカードを選ぶ。A: 決定。B: 戻る（タイトルのみ）。OPTION: ポーズ。

## 4. 必須
- 起動時の注意文（1文ずつ改行、原文どおり）。STARTかAで先へ。

## 5. 合格条件
1. ゲームの中身がGB版と一致: 同じシードと同じ入力で、配り・ペア捨て・引いたカード・順位がGB版と全手一致（24シード）。
2. 注意文が1字も違わない。
3. 音割れ・途切れなし、テンポがGB版と同じ。
4. 20分の連続プレイで再起動しない（ウォッチドッグ確認）。
