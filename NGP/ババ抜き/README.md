# ババ抜き（ネオジオポケット）

> これはフリーで配布されたゲームです。製品版はありません。もし買われた方がいたらそれは詐欺です。警察に相談してください。
> GrokBOTでチームを組んで作成しました。

## ダウンロード
- [babanuki_ngp.ngp](babanuki_ngp.ngp)：ネオジオポケット（白黒）用のROMです（512KB）。

## 動かし方
- ネオジオポケット用のエミュレーターで開いてください。動作を確かめたのは **mednafen（ngp）** です。

## 操作
- スティック左右：引くカードを選ぶ
- A：決定
- B：戻る（タイトルのみ）
- OPTION：ポーズ

## どんなゲーム？
CPUと遊ぶトランプのババ抜きです。GB版のルールとCPUの考え方をそのまま移しました。
