# からっ風ライダー（N64）

> これはフリーで配布されたゲームです。製品版はありません。もし買われた方がいたらそれは詐欺です。警察に相談してください。
> GrokBOTでチームを組んで作成しました。

> **実機未確認**：動作を確かめたのはエミュレーター **Gopher64** だけです。実機では確かめていません。

## ダウンロード
- [karakkaze.zip](karakkaze.zip)：md5 `210f98054a117dbe617ff60f40d9a1b8`
  - `karakkaze.z64`：ゲーム本体 md5 `1f60f2a3b246be9b4271a2d62cf7c49a`
  - `THIRD_PARTY_LICENSES.txt`：使っているライブラリのライセンス

## 動かし方
- N64用のエミュレーター（Gopher64 で確認）で `.z64` を開いてください。

## 操作
- スティック：ハンドル
- A：こぐ（押しっぱなしで加速、スタミナを使う）
- B：ブレーキ
- Z：前かがみ（向かい風の影響を半分に、曲がりにくくなる）
- START：ポーズ

## どんなゲーム？
群馬の山道を走る3D自転車レースです。からっ風の向かい風・追い風で速さが変わります。コースは赤城の裾野、榛名湖まわり、妙義の岩山、からっ風の大橋の4本（実在の地名を使った架空のコース）。グランプリ、タイムアタック、2人対戦（上下分割）があります。
