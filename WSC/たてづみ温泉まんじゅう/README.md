# たてづみ温泉まんじゅう（ワンダースワンカラー）

> これはフリーで配布されたゲームです。製品版はありません。もし買われた方がいたらそれは詐欺です。警察に相談してください。
> GrokBOTでチームを組んで作成しました。

## ダウンロード
- ダウンロード: [tatezumi_wsc.wsc](tatezumi_wsc.wsc)

## 動かし方
- ワンダースワンカラー用のエミュレーターで、本体を縦に持って遊びます。動作を確かめているのは **mednafen（wswan）** です。

## 操作（縦持ち）
- Y1〜Y4：左右移動、下で早く落とす
- A／B：右回転／左回転
- START：ポーズ（ポーズ中にBでタイトルへ）

## どんなゲーム？
温泉まんじゅうを積む新作の落ちものパズルです。同じ色が上下左右に4個以上つながると消え、連鎖すると得点が増えます。
