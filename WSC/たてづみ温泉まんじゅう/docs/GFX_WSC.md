# たてづみ温泉まんじゅう WSC グラフィック（GBグラフィック）
- ロゴは手で縁と影をつけた。

## 画面モードとタイル
- `ws_system_set_mode(WS_MODE_COLOR_4BPP_PACKED)`。1 タイル 32 バイト、1 バイトに 2 点、**上位 4bit が左の点**。
- 全 233 枚を `WS_TILE_4BPP_MEM(0)`＝0x4000 に 0 番から読む（残り 279 枚空き）。`WSE_RESERVE_TILES(0, 512)`。
- 0 番は空（全部透明）。色 0 は透明なので、SCR1 のタイルは色 0 を使っていない。

| 番号 | 中身 |
|---|---|
| 0 | 空 |
| 1〜32 | まんじゅう：`GFX_MANJU_TILE(c,f,q)`。c=0 白,1 茶,2 緑,3 桃。f=0 通常,1 消える。q=0..3 は縦向きで 左上,右上,左下,右下 |
| 33〜99 | 文字（`gfx_ascii[c-0x20]`、`MSG_*`）。文字の地は板の色なので、そのまま板の上に置ける |
| 100〜121 | 湯（100-103）、岩、湯気、木の壁（112 左,113 右）、ふち、夜空、板（43=空白と同じ,120,121） |
| 122〜226 | ロゴ（`gfx_title_fg_map` に並び済み） |
| 227〜232 | 窓の木の枠：227 上（`T_WIN_TOP`）、228 下（`T_WIN_BOTTOM`）、229〜232 角（`T_WIN_TL/TR/BL/BR`）。左右の辺は木の壁 112/113 をそのまま使う。パレット 1 |

## パレット
| 番号 | 使い道 |
|---|---|
| 0 | UI の板と文字（1 文字、2 影、3 板、6/7 板のふち） |
| 1 | 温泉（湯、岩、木、湯気、夜空） |
| 2 | ロゴ |
| 8〜11 | まんじゅう 白・茶・緑・桃。BG でもスプライトでも同じ（スプライトのパレット欄は 0〜3） |

- 白＝丸＋♨の印、茶＝山形（下が平ら）＋焼き目 2 本、緑＝角の丸い四角＋葉っぱ、桃＝横に平たい楕円＋桜。色が見分けにくくても形と印でわかる。
- 消える絵＝つぶれた形、目が「><」、四隅に星。

## 回転のきまり（いちばん大事）
本体を**反時計回りに 90 度**回して持つ前提。タイルは**時計回りに 90 度回した状態で保存**してある。
- 縦向きの点 (x,y)（144x224）→ 画面の点 (223-y, x)
- 縦向きのタイル (lx,ly)（18x28）→ 画面のマス (27-ly, lx)：`GFX_CELL(lx,ly)`＝`(lx)*32 + 27-(ly)`
- 縦向き 8x8 スプライトの左上 (x,y) → `GFX_SPR_PX`=216-y、`GFX_SPR_PY`=x。**ws_sprite_t は attr, y, x の順**なので、`.x=GFX_SPR_PX, .y=GFX_SPR_PY`。
- 16x16 のまんじゅうを縦向き (x,y) に置くとき：q=0 (x,y)、1 (x+8,y)、2 (x,y+8)、3 (x+8,y+8)。
- もし実機で逆向き（時計回りに持つ）だったら、タイルは作り直さずに直せる：マップは全部の左右・上下反転ビット（0xC000）を立てて、置き場所を (lx', ly')=(17-lx, 27-ly) にする。
- mednafen で縦向きの印（`vertical = true`）の ROM を作って、背景・盤面（SCR2）・スプライトがこの通りに出ることを確かめた（見本と同じ絵になった）。実機では確かめていない。

## 配置（縦向きのタイル単位）
- 0 行：とくてん（1,0）／数字 7 桁（10,0）。1 行：さいこう（1,1）／（10,1）
- 2〜3 行：つぎ（4,2）、次の組は（7,2）から 32x16（スプライト 8 枚か SCR2）
- 盤面：（3,4）から 12x24 タイル＝96x192。両わきの 2 列と 15 列は木の壁
- 仕様の「下：段と連鎖数」は、盤面が 4 行目から 27 行目まで全部使うので下に余白がない。そこで**両わきの下**に置いた：左「だん」（0,23）と数字（0,24）、右「れん／さ」（16,22）（16,23）と数字（16,24）。各 2 桁
- おすすめの重ね方：SCR1＝背景（`gfx_play_map`）、SCR2＝積んだまんじゅう（空マスは 0）、スプライト＝落ちている組。

## ポーズとゲームオーバーの窓
- 盤面の真ん中に出す小さい窓。縦向きで（4,13）から 10x5 タイル（`GFX_WIN_LX/LY/LW/LH`）。盤面の木の壁と同じ木で枠、中は板（120 番と同じ、パレット 0）、まん中の行に「ポーズ」「ゲームオーバー」（`MSG_PAUSE`/`MSG_GAMEOVER` と同じ文字タイル）。
- 字数が奇数（3 字・7 字）なので、文字は窓の中で半タイル左に寄る。
- 画面の上では（10,4）から 5x10（`GFX_WIN_PX/PY/PW/PH`）。
- 配列（どれも `__far`、memcpy で）：
  - `gfx_pause_win[50]` / `gfx_gameover_win[50]`：画面の向きのままの 10 行 x 5。そのまま行ごとに memcpy。
  - `gfx_pause_map[504]` / `gfx_gameover_map[504]`：`gfx_play_map` と同じ 28x18 の全画面。窓の外は 0（透明）。
  - `gfx_pause_win_l[50]` / `gfx_gameover_win_l[50]`：縦向きの 5 行 x 10。要素 (x,y) を `GFX_CELL(GFX_WIN_LX+x, GFX_WIN_LY+y)` に置く（RAM に写してから）。
- SCR2（積んだまんじゅう）に重ねると、その下のまんじゅうが消える。窓を閉じたら盤面を描き直すこと。

## 読み込み方
- **`__far` 配列は memcpy で**。テストで `__far` の表を 1 つずつ読むループを書いたら、スプライトが崩れて止まった。`gfx_manju_tiles`・`gfx_ascii`・`MSG_*` も、使う前に memcpy で RAM に写すこと。
- 注意書きの絵はこのファイルに入っていない（ぐんまと同じく、先に注意書きのタイルを読んで、終わったら読み直す）。
