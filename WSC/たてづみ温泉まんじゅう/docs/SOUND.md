# サウンド（GB音楽）たてづみ温泉まんじゅう WSC

曲と効果音はすべてオリジナル（GB音楽の作曲）。温泉街とまんじゅうの、明るく覚えやすい曲。

## 番号表
| 種類 | 番号 | 名前 | 使う場面 | ループ | ch |
|---|---|---|---|---|---|
| BGM | 0 | `MUS_TITLE` | タイトル | する | 1〜4 |
| BGM | 1 | `MUS_PLAY` | プレイ中 | する | 1〜4 |
| ジングル | 2 | `MUS_OVER` | ゲームオーバー | しない（終わると `bgm_playing()`=0） | 1〜4 |
| SE | 0 | `SE_MOVE` | 左右に動かす | | 2 |
| SE | 1 | `SE_ROT` | 回す（A/B どちらも） | | 2 |
| SE | 2 | `SE_LAND` | 着地 | | 4 |
| SE | 3 | `SE_CLEAR` | 消える（1連鎖目） | | 2 |
| SE | 4〜9 | `SE_CHAIN2`〜`SE_CHAIN7` | 2〜7連鎖目（連鎖ごとに全音ずつ高くなる） | | 2 |
| SE | 10 | `SE_LVUP` | 段が上がる（G5 C6 E6 G6→C7） | | 2 |
| SE | 11 | `SE_DECIDE` | メニュー決定（C6→G6） | | 2 |
| SE | 12 | `SE_CANCEL` | メニュー取消（G5→C5） | | 2 |
| SE | 13 | `SE_PAUSE` | ポーズ（A5・E5） | | 2 |

- 連鎖は `sfx_play(SE_CHAIN(n))` と書けば、n=1 で SE_CLEAR、7以上（倍率64）は SE_CHAIN7 になる。

## 組み込み方
1. 起動時に `snd_init()` を1回（波形メモリを IRAM の 64 バイト境界に置き、0x8F に設定する。ゲーム側で 0x8F と波形メモリを書き換えない）。
2. **1フレーム(75.47Hz)に1回だけ** `snd_update()` を呼ぶ（メインループでも VBlank 割り込みでもよいが、両方から呼ぶと速くなる）。テンポはこの回数で決まる。
3. `bgm_play(MUS_TITLE)` → ゲーム開始で `bgm_play(MUS_PLAY)` → 負けたら `bgm_play(MUS_OVER)`。
   **ポーズ（仕様書7章）:** ポーズで `bgm_stop(); sfx_play(SE_PAUSE);`（順番はどちらでもよい）、再開で `bgm_play(MUS_PLAY);`（頭から鳴る。再開時に SE_PAUSE を鳴らしてもよい）。**ポーズ中も `snd_update()` は毎フレーム呼び続ける**（止めると SE_PAUSE が鳴りやまない）。`bgm_stop()` は鳴っている SE を止めないので、ポーズ音は止めた直後でも最後まで鳴る（テスト ROM で確認）。
4. 効果音: 移動 `SE_MOVE`、回転 `SE_ROT`、着地 `SE_LAND`、消えたとき連鎖数 n で `sfx_play(SE_CHAIN(n))`、30個消して段が上がったら `SE_LVUP`、メニューで `SE_DECIDE` / `SE_CANCEL`。同じ ch の SE は後から鳴らしたほうが勝つ（着地と消えるは ch が違うので同時に鳴る）。
5. 使うポート: 0x80-0x8B, 0x8E, 0x8F, 0x90, 0x91。ゲーム側では触らない。
- ch1=メロディ（やわらかい波形）、ch2=伴奏（25%矩形波）、ch3=ベース（三角波）、ch4=ドラム（ノイズ）。ch2 の SE の間は伴奏が、着地 SE の間はドラムが休む（メロディとベースは止まらない）。
- ch2 の PCM（ボイス）と ch3 のスイープは使っていない。

## ぐんま版からの変更
- GB のフレーム換算をやめ、BPM から 16分音符の進みを 75.47Hz で直接計算（誤差 0.01% 以下）。
- 4ch とも曲に使う（ノイズでドラム）。音色は波形メモリで作った（ch1 やわらかいリード、ch3 三角波）。
- 音量の減衰はフレームごとにソフトで行う。
