# たてづみ温泉まんじゅう WSC版 仕様書（GB企画・新作）

## 1. 概要
- ワンダースワンカラー用の新作落ちものパズル。本体を縦に持って遊ぶ（144x224、18x28マス）。
- Wonderful toolchain(C)、mednafen_wswanで確認。音はぐんま（WS）の音の仕組みを使い回す。
- 人を出す場合は大人とわかる見た目、アニメ調、服は水着まで。ご褒美の絵は入れない。

## 2. ルール
- 盤面は横6x縦12（1マス16x16）。上から「まんじゅう」が2個1組で落ちてくる。色は4色（白・茶・緑・桃）。
- 同じ色が縦か横に4個以上つながると消える。消えたあと上のものが落ちて、また消えると連鎖。
- 一番上の真ん中の列（左から3列目）がふさがったら負け。
- 得点 = 消した数 x 10 x 連鎖倍率（1,2,4,8,16…最大64）。
- 落ちる速さは消した数30個ごとに1段上がる（14段まで）。
- 次の組を盤面の上に表示する。
- モードは「エンドレス」1つ。最高得点は電源を切るまで覚える（保存はしない）。

## 3. 画面（縦持ち 144x224）
- 上2行: 得点と最高得点。
- その下2行: 次の組。
- 中央: 盤面（96x192）を真ん中に置く。
- 下: 段と連鎖数。

## 4. 操作（縦持ち）
| ボタン | 役割 |
|---|---|
| Y1〜Y4 | 縦持ちの十字（左右移動、下で早く落とす） |
| A / B | 右回転 / 左回転 |
| START | ポーズ |

- 横持ちのX側のボタンは使わない。

## 5. 音
- BGM: タイトル、プレイ（ループ）。
- ジングル: ゲームオーバー。
- SE: 移動、回転、着地、消える、連鎖（連鎖数で高さが上がる）。

## 6. 合格条件
1. 24シードで同じ入力を入れると、毎回同じ得点と結果になる。消える判定と連鎖の数を、PCで書いた答え合わせ用のプログラムと照らして一致する。
2. 注意書きが一言一句同じ。
3. 音割れ・途切れがない。
4. 20分遊んで止まらない。

## 7. 決定事項（音）
- 追加SE: 段が上がる音、決定、取消、ポーズ。危険時の速い曲は作らない。
- ポーズ中は `bgm_stop()` で曲を止め、再開時は頭から鳴らす。
- 効果音の間に伴奏・ドラムが少し止まるのは可。

## 7追記 企画決定（2026-10-15）
- 乱数: 16bit xorshift `x^=x<<7; x^=x>>9; x^=x<<8;`。シードは0以外をそのまま。1組ごとに2回呼び、下位2bitを色にする（1回目が軸）。色0〜3はBGパレット8〜11、スプライトパレット0〜3（白、茶、緑、ピンク）。
- 消える条件: 上下左右につながった同じ色の塊が4個以上。
- 出てくる位置: 左から3列目の一番上。軸が下、相方が上。回転で当たったら1マス横にずらし、それでも入らなければ回転しない。
- 落ちる速さ: 段に合わせて60フレームから4フレームずつ速くなり、最速は8フレーム。下に着いてから30フレームで固定。出てくる位置がふさがっていたら負け。
- RAMの場所: プログラマーが docs/ に書く。照合はフレームではなく何組目の着地かで行う。
- 回転で当たったとき: 相方の反対側へ1マスずらす。上下向きのときは左、だめなら右。どちらも入らなければ回転しない。
- 30フレーム固定: 動かしたり回したりしても数え直さない。足元が空いたら取り消し、次に着地したら0から数える。
- 段: 1＋消した数÷30、最大14段。落ちる速さは60−4×(段−1)フレームで、14段で8フレーム。
- 出てくる行: 軸は上から2行目、相方は一番上の行。
- 固定: 接地した最初のフレームを1と数え、30フレーム目に固定。
- 乱数を呼ぶ順番: 開始時に最初の組を作り、組を出すたびに次の組を作る。
- ポーズ中にBでタイトルへ戻る（SE_CANCEL）。
- 下を押している間は2フレームに1段落ちる。30フレーム固定は変えない。
- 「つぎ」は軸と相方を横に並べて表示する。
- 連鎖数の表示は新しい組が出たら0に戻す。
- 再開直後にch1が1フレーム早く進むのは、ドライバーの仕様として容認。
- 固定の数え方（訂正）: そのマスへ落ちてきたフレームを1と数え、30フレーム目に固定する（ROMの実装を正とする）。
- 長押し: 押した瞬間に1マス動き、12フレーム後から3フレームごとに動き続ける。
- 合格判定は1組ずつの着地照合で行う。入力を通しで流す照合は、エミュレーターの入力遅れがあるため参考扱い。
