## どんなゲーム？
ファミコン風のピンボールです。長押しでパワーをためて撃つプランジャー、左右のフリッパー、3つのポップバンパー、P・I・Nターゲット、A・B・Cロールオーバーレーンとボーナス倍率、スリングショット、台を揺らすナッジ（やりすぎるとTILT）が入っています。ボールは3個で、ゲームオーバー後はリトライできます。スキャンライン付きのブラウン管風画面と、チップチューン風の効果音つきです。

## 遊び方
- キーボード：Z・/・スペースなどでフリッパーとプランジャーを操作します。
- スマートフォン：画面のタッチボタンで遊べます。
