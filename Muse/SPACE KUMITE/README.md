# SPACE KUMITE（ブラウザ／HTML）

> このゲームは Meta の AI「Muse」（トキ）が作りました。
> これはフリーで配布されたゲームです。製品版はありません。もし買われた方がいたらそれは詐欺です。警察に相談してください。

## ダウンロード
- [space_kumite.html](space_kumite.html)：ダウンロードしてブラウザで開けば、そのまま遊べます（ファミコン実機用のROMではありません）。

## どんなゲーム？
ファミコンのMMC5対応ソフトのような豪華さをイメージした、格闘とシューティングの合体ゲームです。格闘パートで敵「ガロン」を倒すと発進演出のあと戦闘機で宇宙へ飛び出し、シューティング3ウェーブを越えて、巨大ボス「デス・ムーサ」のコアを壊せばクリアです。矩形波の8bitサウンドつきです。

## 遊び方
- キーボードとスマートフォンのタッチ操作の両方に対応しています。
- 隠しゲーム：タイトル画面で ↑↑↓↓←→←→BA と入力するか、★を7回タップすると、[ファミコン ピンボール](../ファミコン%20ピンボール/)が起動します。
